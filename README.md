# CA Glyph DIY Roll Printer

셀룰러 오토마타로 생성된 흑백 글리프를 롤지에 한 행씩 인쇄하는 DIY 출력 장치 프로젝트다. 이 저장소를 프린터의 부품 선정·회로·기계 설계·주문 기록과 이후 구현의 작업 거점으로 사용한다.

현재는 설계와 구매 준비 단계다. 조립·인쇄 검증이 끝난 키트나 실행 가능한 프린터 소프트웨어는 아니다.

제작 기준은 **297mm 롤지 /270mm 인쇄 폭 /흑백 /커터 없는 행 단위 출력**이다. 받침의 목표 평면은600 x440mm이며 완성 장치의 전체 외형 치수는 아니다. 400mm 용지 확대는 이번 계획에서 제외했다.

오늘 주문 판단은 [시험용 주문 사양표](printer/ORDER_v2_2026-10-12.md#주문할-수-있는-범위)부터 읽는다. 최신v25는 E1 전산봉을 직접 절단하는1m3본에서 손잡이닷컴의 길이 지정 절단품5개로 바꿨다. 첫 조립·감독하 시험용 모델·옵션·수량이며 실제 인쇄/통전/무인 전시 승인은 아니다. 본체 부품·3D 제작비 **1,699,143원**은 E1 새 가격 확인 전 이전 배정을 잠정 유지한 값이고, 공구·측정/소모품200,000원은 별도다. 사용자 요청대로 배송·예비비는 이 합계에서 제외한다. 최종 결제 가격과 재고/도착일은 별도이며 조립설명서·최종 도식화는 주문 이후 작성한다.

**최신 조립 조건:** 직접 금속 가공·회로 제작을 줄인다. D1/E5 원자재, G5 기본 케이스, I4/A7 직접 납땜용 소부품은 조달 간소화 검토 중이라 일괄 주문하지 않는다. 볼트·너트는 유지하고 미세 전자부품의 보드화를 우선한다. [6묶음 구매 안내](printer/ORDER_v2_2026-10-12.md#먼저-볼-구매-묶음)와 [수축튜브·제어부 점검](printer/PLAN_v25_2026-10-13.md#수축튜브는-두-용도다)을 먼저 본다. 새 가공·조립비는 위 잠정 예산에 아직 반영하지 않았다.

## 시작 위치

전기부는 **조립·지정 기능검사 완료품**, 케이블은 **양끝 가공·절연·검사 완료품**으로 받는 것이 최신 조건이다. 사용자가 도안의 번호대로 고정·연결할 수 있게 준비하되, 현재 완성 키트를 확보한 것은 아니다. [수령 기준과 미확정 범위](printer/PLAN_v25_2026-10-13.md#완성-배선-수령-기준)를 우선한다.

- [현재 상태](CURRENT.md): 지금 정한 것, 남은 일, 다음 작업.
- [프로젝트 기준](MANIFESTO.md): 원하는 결과와 지킬 조건.
- [작업 지침](AGENTS.md): 자료를 읽고 기록하는 방법.
- [프린터 문서 안내](printer/README.md): 계획·재료표·연결표·참조 도면의 진입점.
- [시험용 주문 사양표](printer/ORDER_v2_2026-10-12.md): 현재39개 그룹의 옵션·수량·계획액·구매 링크와 통전 전 조건.
- [수령 후 시험 순서](printer/ORDER_v2_2026-10-12.md#수령-후): 무전원 조립부터 한 행 출력까지의 단계.
- [재료표 v25](printer/BOM_v25_2026-10-13.md): 최신 수량과 잠정 예산. E1 절단품 가격 확인 후 정산.
- [체결재 개별 구매표](printer/SELECTION_v23_2026-10-12.md): 기존15종과 원자재. v24 추가 수량을 함께 적용한다.
- [배선·케이스·보관 부속](printer/SELECTION_v24_2026-10-12.md): 가동선·고정 신호선·스위치 장착·케이스·청소/보관과 추가 체결재.

## 역할 분리

```text
메인 PC / TouchDesigner
    +-- 비주얼 데이터 --> 기존 Pi / 디스플레이
    |
    +-- 완성된 글리프 행 --> 새 프린터 Pi
                               +-- USB --> Uno --> 분사 회로 --> 잉크 헤드
                               +-- I4 --> 드라이버 --> X축·앞뒤 급지
```

기존 Pi·전원·microSD는 디스플레이용으로 유지한다. 프린터용은 새로 구매한다. 프린터 Pi에는 세그멘테이션·CA 생성·전시 영상 재생을 올리지 않는 설계다.

3D 출력은 사용자가 직접 또는 제작 의뢰로 진행하며150,000원을 배정한다. 필라멘트·출력 업체 조사는 제외한다. 제작 방식과 별개로 고정부 치수와 시험 끼움은 확인해야 한다.

## 기록 상태

기존 `td mcp/printer` 자료를 이 저장소의 `printer/`로 복사했고 이전 버전·원작 참조 자료를 보존했다. 앞으로 프린터 기록은 이 저장소에서 갱신한다. 기존 폴더는 이전 작업 사본으로 남긴다.

원격 주소는 [nujoe/cstm_printer_CA_glyph](https://github.com/nujoe/cstm_printer_CA_glyph)다. 2026-10-12 사용자 요청에 따라 v23 전체 기록을 main에 게시했고 최신v24와 시험용 주문표도 이 저장소에서 관리한다. 원격과 로컬을 대조한 결과는 CURRENT에 기록한다. 이후 실물 시험 결과는 실제 수행한 범위와 함께 기록한다.

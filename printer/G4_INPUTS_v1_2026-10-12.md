2026-10-12. [I4 접점 회로](I4_WIRING_v1_2026-10-12.md)에 사용할 시험용 기준 모델을 선정했다. 소프트웨어·장착·실물 검증 완료 또는 전시용 안전 차단기를 뜻하지 않는다.

## 2. 기존 회로를 유지하는 이유

Panasonic [AEQ 제품 자료](https://na.industrial.panasonic.com/products/switches-encoders-interface-devices/switches/series/26332)는3V/100µA부터의 미소 부하와 SPDT 접점을 명시한다. 현재 접점 회로의 명목값은 다음과 같다.

```text
3.3V -- 10k 풀업 --+-- Pi 입력
                  |
                 1k
                  |
                 NC
                접점
                 COM
                  |
                 GND

NO 단자: 미연결·절연
```

- 닫힌 접점 전류: `3.3 / (10,000 + 1,000) = 0.00030A`, 약0.30mA.
- 닫힌 상태의 Pi 입력: 약0.30V. 누름·단선으로 열리면 약3.3V가 목표다.
- 따라서 최대100mA 정격만 보고 고르는 대신 실제 작은 부하를 지원하는 모델을 선택한다. 전원 전압·저항 공차·노이즈와 실제 LOW/HIGH는 측정해야 한다.
- 원점BCM5/물리29, 끝단BCM6/물리31, 정지 요청BCM16/물리36을 유지한다. 전압 변환이나 새 풀업 저항을 추가하지 않는다.

COM을논리GND에, NC를1k 직렬 저항 경유 입력에 연결한다. NO는 비운다. 몸체·도면·멀티미터로 접점을 식별하며 왼쪽/오른쪽 위치를 추정하지 않는다. 원점·끝단·정지는 독립 입력3개이며 접점을 한 회로로 합치지 않는다. GPIO에는5V·24V를 넣지 않는다.

## 3. 장착과 시험

AEQ10410은작은 핀형 스위치이지 누르기 쉬운 큰 패널 버튼이 아니다. 정지 요청 입력은 손이 닿는 고정 위치에 두고 노출 단자를 절연한다. v24에서 [제조사 PDF](reference/AEQ_series_datasheet.pdf)5쪽의 몸체13.3×8.4mm, 장착홀Ø3.0 두 개/중심 간8.3mm를 대조했다. 몸체당 M3×16 두 개·와셔4개·너트2개를 기존 D4 세트에서 쓴다. 레일 원점/끝단 P10은 각각 M5×10 두 개·와셔2개·20-M5 너트2개로 고정한다. [배선·고정 수량](SELECTION_v24_2026-10-12.md#스위치케이스의-고정)을 따른다. 출력 업체·재료를 새로 조사하지 않으며 최종 누름부/홀더 모델과 누름 위치는 실물 후 제공한다.

원점·끝단에는 캐리지가 핀을 작동 방향으로 누르도록 고정한다. 핀에 횡방향 하중을 주거나 스위치를 기계적 충돌 받침으로 쓰지 않는다. 스위치 감지 후 정지까지의 이동 여유와 별도 기계 끝단을 검토한다.

1. 모든 전원·USB를 뺀 상태에서COM-NC가 평소 연결되고 누르면 끊기는지3개 각각 검사한다.
2. 모터24V와헤드18V를 물리적으로 분리하고 Pi 입력의닫힘/열림 전압을 측정한다.
3. 코드가 준비되면 단선·누름·누른 채 시작·해제 상태를 검사한다. 정지 요청은 해제만으로 자동 재개하지 않는 시험 조건을 둔다.
4. 낮은 속도의 헤드OFF 모션에서 원점과 끝단의 반복 위치·정지 여유를 확인한다.

단선의열림은 감지할 수 있지만 입력이GND로 단락되면 정상 닫힘으로 오인할 수 있다. 접점 바운스 처리와 통신/프로세스 고장 보호는 이후 구현·시험 범위다. **아직 코드가 없으므로 연결해도 정지 기능은 없다.** 이 입력은 전원 차단·안전 인증 비상정지·무인 전시 고장 보호를 대신하지 않는다. 기존24V/18V 수동 차단을 유지한다.

## 4. 근거와 남은 조건

[제조사 원문 PDF 사본](reference/AEQ_series_datasheet.pdf)은 공급처가 제공한 자료를 그대로 보관한 것이다. 스위치 도면을 프린터 고정부의 완성 도면으로 해석하지 않는다.

현재 완료: 기준 모델·수량·실제 판매 화면·명목 회로 계산·연결 방향·장착홀 규격·체결재 수량·시험 순서. 남음: 주문 시 수령 예정일·실물 접점·고정부 최종 모델·장착/누름 조정·파형·정지 코드·장시간 운영. 펌웨어·통전·구매는 하지 않았다.

알리익스프레스는 현재 브라우저 보안 정책으로 직접 접근이 차단되어 후보를 확인하지 못했다. 사용자가AliExpress 배송 일정은 수용했으므로 배송 확인 부족만으로 제외하지 않는다. Alibaba는 제외한다. 주소·계정 정보를 가린 상품 옵션/사양 화면을 받은 뒤 별도로 대조하며, 접근 실패를 품절이나 동일 모델 부재로 단정하지 않는다.

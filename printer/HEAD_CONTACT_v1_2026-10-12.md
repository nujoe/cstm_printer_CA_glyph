# 헤드 리본 접점과 범용 변환보드

2026-10-12. 대상은 Q2299A 홀더, C6602A 카트리지, MIKROE-233 두 장이다. [기존 Uno 연결표](HEAD_TEST_v1_2026-10-11.md)의 신호 배정은 유지한다. 이 표는 원작 회로를 새 모듈 연결로 옮긴 **참조 배선표**다. 실제 Q2299A 리본이나 변환보드의 핀1을 확인했다는 뜻은 아니다.

## v18 구매 대상 결정

[AliExpress1005012643948143](https://ko.aliexpress.com/item/1005012643948143.html)의 `Straight-16P-1PCS` 1개를 **무전원 확인용**으로 선정했다. 아래 후보 비교는 조사 이력이다. A3 배정15,000원을 유지하고 재선정에 필요한15,000원은 기존 수리 예비비 안에 남긴다. 소켓 정격 미확인 상태에서18V를 연결하라는 결정이 아니다. 수령 후 삽입·잠금·접점 대응이 맞지 않으면 사용하지 않는다.

## 1. TS3643 대신 사용할 수 있는 보드

필요한 것은 전압 변환기나 분사 컨트롤러가 아니라 **리본의 16개 접점을 각각 연결 가능한 패드로 꺼내는 수동 보드**다. 브랜드보다 아래 조건이 중요하다.

| 확인할 것 | 필요한 조건 | 주문에서 제외할 것 |
| --- | --- | --- |
| 리본 쪽 핀 수 | 16핀 | 15핀 카메라 보드, 임의로 끼우는 18/20핀 보드 |
| 리본 쪽 피치 | 1.0mm | 0.5mm 옵션 |
| 커넥터 | FFC/FPC 소켓 납땜 완료 | 빈 PCB 또는 소켓만 판매하는 상품 |
| 신호 인출 | 16개 독립 신호를 2.54mm 핀/패드로 꺼냄 | FFC-to-FFC 연장보드 |
| 기계 결합 | Q2299A 리본 두께와 금속 접점 면에 맞음 | 이름이나 대표 사진만으로 호환 판단 |
| 전기 사용 | 소켓의 전압/전류 정격과 전원 패턴 확인 | GPIO 전용이라고만 적힌 무정격 제품을 헤드 전원용으로 확정 |

소켓의 위/아래 접점은 실제 리본 금속면과 만나야 한다. 번호 순서가 반대인 것은 배선표에서 대응할 수 있지만, 접점이 만나지 않거나 리본을 비틀어야 하는 제품은 쓰지 않는다. 2.54mm 핀헤더 납땜과 헤드 전류 경로의 짧은22AWG 배선은 남을 수 있다.

검색어: `16P 1.0mm FFC FPC to 2.54mm DIP adapter board soldered connector`.

[원작 설명](https://homofaciens.de/technics-machines-printhead-hp6602_en.htm)은 리본 쪽16핀/1mm와 무전원 연결 검사를 명시한다. [TS3643](https://tinkersphere.com/cables-wires/3643-16-pin-05mm-1mm-pitch-fpc-to-dip-breakout.html)는 해당 형태의 기준 후보다. `Soldered Side: 1mm / Type B`는 그 판매처의 옵션명이지 일반 FFC 케이블의 접점 동면/반대면 규칙이 아니다.

### 사용자 화면으로 확인한 추가 후보

[2026-10-12 제공 화면](reference/ffc_candidate_2026-10-12.png)에서 선택값은 **bent pin / 1pcs / 1.0mm / 16P**다. `16페이지`는 이 화면에서16P 옵션의 자동 번역이다. 필요한 핀 수·피치 옵션이 선택됐다는 증거이며 A3 구매 후보로 기록한다.

- `bent pin`은2.54mm 인출 헤더의 꺾임 형태다. FFC 소켓의 상/하접점이나 케이블 TypeA/B를 뜻하지 않는다.
- 사용자가straight/bent 납땜 옵션을 고를 수 있다고 확인했다. **권장 구매 옵션은1.0mm /16P /straight /1pcs를수량1개**다. 일자로 선 핀에 암 점퍼를 꽂고 번호를 검사하기 편해 권장한다. bent도 같은 보드·핀 배선이면 기능상 대체 가능하며 낮은 높이/옆 방향 배선이 필요할 때 쓴다. 이는 리본 접점 면·전기 정격을 해결하는 선택은 아니다. 기존 제공 화면의bent 선택과 권장straight를 구분한다.
- `1pcs`는보드1개 옵션이다. 고객당1개 제한에 맞춰필수1개만준비하며 예비 구매는 제외했다. 두 분사 모듈이같은16핀 보드1개를 나눠쓴다. 따라서 대표 사진에보드3개가 보여도3개 세트라고 해석하지 않는다.
- 대표 사진은6/50/10핀의0.5mm 보드 예시다. 소켓·헤더가 붙은 형태로 보이지만 **실제16핀/1mm 옵션의 완성 사진·소켓 접점 면·리본 두께·전기 정격은 확인되지 않았다.**
- 화면의1,499원은신규 회원 전용 표시값이고 취소선 원가는3,669원이다. 신규 할인 적용 여부·배송/세금·최종 결제액은미확정이다. A3 배정15,000원은 유지한다.
- 이후 사용자가 정확한 주소를 제공해 이 후보를 [AliExpress1005011914623154](https://ko.aliexpress.com/item/1005011914623154.html)로 특정했다. 이전33026153891과는 다른 상품이다. 장바구니·계정·추적 매개변수는 기록하지 않고 상품 주소만 보관한다. 직접 페이지 접근은 하지 않았으며 옵션 근거는 사용자 제공 화면과 답변이다.

G마켓의 마지막 옵션 `같은면 TypeA / 후방 B`는 **동봉 FFC 케이블 양 끝의 접점 방향**이다. 변환보드 소켓의 상접점/하접점을 선택한다는 뜻이 아니며 TS3643의 `Soldered Side` 옵션과도 다르다. Q2299A 자체 리본을 직접 꽂는다면 동봉 케이블을 추가할 필요가 없다. 사진의2.54mm 핀헤더는 납땜되지 않아 헤더 또는 전선 납땜이 남는다. 이 상품을 선택할 경우 설명상 **1세트가 보드2개**이므로2세트를 중복 구매하지 않는다. 17,990원은 기존 A3 배정15,000원보다2,990원 높으며, 아직 후보 비교값이지 예산 변경이나 구매 확정이 아니다.

## 2. 그림상 접점과 실제 핀 번호 구분

참조는 [원작 Figure9 회로](https://homofaciens.de/technics-machines-printhead-hp6602_en.htm)의 오른쪽 리본이다. [보관한 그림](reference/worldprinter/head_circuit.jpg)에서 **리본 끝이 왼쪽, 케이블이 오른쪽으로 뻗는 방향**으로 볼 때 위에서부터 `RC01`~`RC16`이라 부른다.

`RC`는 이번 문서의 위치 라벨이다. HP의 공식 핀 번호, 변환보드의 실크 숫자, 실제 노즐의 공간 순서가 아니다. 원작의 Uno 핀 순서를 복사하지 않고 v10의 Uno 배정을 유지한다.

```text
원작 그림 방향의 리본 접점      이 문서에서 부르는 이름
위쪽  [금속 접점] ---------------- RC01
      [금속 접점] ---------------- RC02
      [금속 접점] ---------------- RC03
                  ...
아래쪽[금속 접점] ---------------- RC16

실물 보드의 1번 패드 = RC01이라고 가정하지 않는다.
```

## 3. 참조 배선표

U1/U2는 v19에서 선정한MIKROE-233 라벨이다. ULN의 입력핀1~8은 출력핀18~11에 대응하며 보드 CN1~CN8의DRV0~7로 나온다. [제조사 회로도 p2](reference/mikrodrive-manual-v100.pdf)와 무전원 연속성을 대조한다. 이전 MCD의JP번호는 사용하지 않는다.

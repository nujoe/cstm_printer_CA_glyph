# 헤드 연결부와 조립 완료품 조사

## 2026-10-13 완성품 중심 재검토

**Q2299A와 C6602A는 유지한다. 기성 보드와 외장 어댑터는 확보 가능한 경로가 있지만, 이 조합에 바로 꽂아 쓰는 재고형 분사 제어 세트는 이번 조사에서 확인하지 못했다.** 모든 배선이 완성된 프린터 키트를 찾았다는 뜻은 아니다. 아래는 구매처 확인과 조립 경로 비교이며 전체 주문 승인이나 BOM 변경이 아니다.

현재 추천은 기존 Pi + Uno, MIKROE-233, DM332T를 유지하고 **남는 신호 인터페이스와 특수 배선만 조립 완료품으로 받는 것**이다. 새 모터 제어기를 도입해 분사 동기화까지 다시 설계하지 않는다. 사용자가 직접 작은 IC와 저항을 납땜하거나 전선을 가공하는 경로는 채택하지 않는다.

### 완성 케이블로 해결되는 범위

- USB A-B 데이터선, 접지 C13 전원코드, Pi 공식 전원은 기존 완성품을 유지한다. 자르거나 납땜할 이유가 없다.
- [Tensility 10-02245](https://www.digikey.kr/ko/products/detail/tensility-international-corp/10-02245/6412280)와 [10-02247](https://www.digikey.kr/en/products/detail/tensility-international-corp/10-02247/6412282)는 각각 5.5×2.5/5.5×2.1mm 잭과 915mm 선이 붙은 부품이다. 이번 조회 재고는 각각1,058/4,057개이며 10-02245 단가는7,006원 표시다. **퓨즈·스위치·분배까지 결선된 전원 하네스는 아니므로 C3 구매 보류를 해제하지 않는다.** 제작자가 활용할 수 있는 부품으로만 남긴다.
- 모터·센서·헤드선은 양끝 커넥터/단자 대응과 길이가 달라 일반 연장선 하나로 전부 해결되지 않는다. 핀 수만 같은 3D프린터 케이블을 자동 대체품으로 넣지 않는다. 특히 헤드 가동선은 완성 후 실제 길이에서 펄스 파형 검사가 필요하다.

- [Adafruit Pixel Shifter](https://learn.adafruit.com/adafruit-pixel-shifter/overview)는 $4.50의 납땜 완료2채널 신호변환 보드다. I4의 기본OFF/출력 차단과 DM332T 입력 구동을 함께 대체한다고 검증한 것은 아니므로 추가 구매하지 않는다.
- [OpenBuilds BlackBox X32](https://docs.openbuilds.com/doku.php?id=docs%3Ablackbox-x32%3Astart)는 여러 모터 드라이버가 통합된 기성 제어기다. 다만 C6602 분사 제어기는 아니고 기존 모션/분사 동기화 변경이 필요하다. 이번 목적에서는 기구·모션 전체를 다시 설계하지 않고 기존 구성을 유지한다.

### 주문 판단

1. Q2299A1개와 C6602A2개는 유지할 시험용 핵심 품목이다. 실물 확보를 먼저 한다면 이 범위의 선구매는 합리적이지만, 보드·배선 수령 전 인쇄 가능을 보장하는 구매는 아니다. 예비 카트리지는 밀봉 보관한다.
2. 현재 핵심 미확정은 **신호 보드의 조립·검사 경로와 전용 하네스의 완성 공급**이다. 같은 기능의 저가 소형 모듈을 계속 늘려 해결하지 않는다. 기존 보호 회로를 빼서 부품 수만 줄이지도 않는다.
3. 전문 조립 경로가 결정되기 전에는 I4/A7 원소자와 A6/C3/C4/G2/G4 원배선 부품을 사용자 직접 제작용으로 일괄 주문하지 않는다. 기존 예산1,699,143원에는 이 제작 서비스의 새 견적이 반영되지 않았다.

최종 실물 분사·급지·발열은 여전히 수령 후 시험이다. 이번에는 구매처와 서비스 범위를 조사했으며 회로·CAD·펌웨어·BOM 수량/가격·예산 시트를 변경하지 않았다.

## 2026-10-11 조사 이력

아래 MCD2803A-02와 이전 FFC 배송 판단은 당시 기록이다. 현재 선정은 위 조사와 [PLAN v25](PLAN_v25_2026-10-13.md)를 우선한다.

## 결론부터

전체 프린터를 레고처럼 꽂기만 하는 키트로 만들 수 있다고 확인한 것은 아니다. 다만 **ULN IC 2개를 직접 납땜하는 대신 국내 나사단자형 모듈 2개를 사용하는 방향**은 찾았다. FFC 변환보드도 납땜 완료 제품이 존재하지만, 목표 기간 내 한국 배송을 확인한 후보는 아직 없다.

순서는 `FFC 연결 -> 헤드 구동 -> X축 -> 급지`로 유지한다. 이번에는 앞 두 부분만 조사했다. 펌웨어 작성, 주문, 판매자 문의, PCB 제작 의뢰는 하지 않았다.

```text
PC/Pi -> Uno R3 -> ULN 모듈 2개 -> FFC 변환보드 -> Q2299A -> C6602A
                        |
                 별도 헤드 전원 후보 18V
```

역할 구분도이며 바로 따라 연결하는 핀별 회로도가 아니다. 헤드용 18V를 Uno 또는 Pi에 넣지 않는다.

- 8개 입력이 ULN에 직접 연결되고 8개 출력이 나사 단자로 나온다. 두 개면 16채널 중12채널을 사용할 수 있다.
- 릴레이나 통신 제어기를 거치지 않는다. 따라서 원작의 직접 노즐 제어를 옮길 후보라는 판단이다. 제조사가 C6602A 전용 호환을 보증한 것은 아니다.
- IC, 단자, FFC 소켓의 미세 납땜 부담을 줄이는 방향이다. Uno -> 모듈의 10핀 입력 헤더 배선, 출력 -> FFC 배선, 전원·GND 연결은 남는다.

### 18V를 아직 바로 넣으면 안 되는 이유

제조사 회로에서 `JP2`가 `VCC_DRIVE`를 Uno측 `VCC` 또는 외부 전원측 `VCC_EXT`와 연결한다. `C1 220uF`는 `VCC_DRIVE`와 GND 사이에 있으나 **콘덴서 정격 전압이 명시되지 않았다**. ULN 칩의 50V 출력 한계가 보드 전체의 전압 정격을 뜻하지는 않는다.

수령 후 필요한 확인은 다음이다.

1. C1 정격이18V보다 높고 여유가 있는지 확인한다. 이번18V 안에서는 최소25V 이상을 기준으로 하며, 맞지 않으면 보드마다 콘덴서1개를 교체하거나 다른 보드를 사용한다. 외부 단자·점퍼 등 보드 부품의 정격도 확인한다.
2. JP2를 외부 전원 선택으로 설정한다. 핀번호보다 기판의 `VCC`, `VCC_DRIVE`, `VCC_EXT` 라벨과 실제 연속성으로 대조한다.
3. 무전원 상태에서18V측과 Uno5V측이 이어지지 않는지, 공통GND·출력/COM 경로가 원작과 맞는지 검사한다.
4. 사용하지 않는 입력은 OFF로 고정한다. 실제 사용 입력도 Uno 부팅·리셋 시 OFF가 되게 배선/펌웨어를 검토한다. 원작에서 손상 사례가 있는D13은 헤드 분사 핀으로 쓰지 않는다.
5. 헤드 없이 더미 부하에서 펄스를 측정한 뒤 실제 헤드를 연결한다. 제조사 IC의 전파 지연 전형값은 실제 배선·부하의 펄스 품질 보증이 아니다.

이 조건으로 **회로가 확인되는 구매 후보**까지는 좁혔지만, 18V 사용 승인·실물 분사 성공은 아직 아니다. 콘덴서 교체가 필요하면 소량 납땜이 남으므로 완전 무납땜 키트라고 부르지 않는다.

## 3. 조립 난도와 다음 순서

줄어드는 작업: ULN2개, 소켓2개, 출력 단자를 만능기판에 납땜하는 일. 모듈 회로를 새로 설계하는 일도 피한다.

남는 작업: 입력 하네스 연결, FFC 핀 대응/연속성 검사, DC 전원 극성 확인, 점퍼 설정, 필요 시 콘덴서 교체, 더미 부하 펄스 시험. 초보자에게 이 과정이 볼트 조립만큼 쉬운 것은 아니다. 다만 원작의 점대점 납땜보다 관리할 연결을 줄이는 방향이다.

다음에는 A3를 확보할 수 있는 정확한 옵션/납기를 정하고, A5의 입력 하네스와 전원 연결부까지 포함한 **최소 분사 시험 주문 목록**을 닫는다. 이후 X축·용지·급지로 넘어간다. 미확정 상태에서 큰 프레임과 모터 전원을 먼저 주문하지 않는다.

모듈 변경을 반영한 계획 예산은 [BOM v8](BOM_v8_2026-10-11.md)에 있으며1,889,920원이다. 이는 배송·세금·공구·교체 예비비650,000원을 포함한 배정액이다. 미확정 부품의 현재 견적이나 지원금 인정 확인은 아니다.

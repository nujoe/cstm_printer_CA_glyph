# 헤드 연결부 구매·결선·시험 v1

2026-10-11 작성. 2026-10-12 v19에서 분사 모듈을 변경했다. 현재 회로·수량·예산은 [계획 v19](PLAN_v19_2026-10-12.md)와 [v19 재료표](BOM_v19_2026-10-12.md), FFC 후보는[헤드 접점표](HEAD_CONTACT_v1_2026-10-12.md)를 따른다. 이번 범위는 **고정된 헤드에서 점을 찍기 위한 연결부**다. 모터·급지·펌웨어 구현은 포함하지 않는다.

## 1. 이번 결정

- Q2299A + C6602A, Uno R3를 유지하고 분사 모듈은 **MIKROE-233 2개**로 변경한다. IC를 직접 조립하는 방식으로 되돌리지 않는다.
- FFC는 **16핀 / 1mm 피치 / 커넥터 납땜 완료 / DIP 인출형**을 사용한다. 현재 우선 비교 후보는[AliExpress1005012643948143](https://ko.aliexpress.com/item/1005012643948143.html)의`Straight-16P-1PCS` 1개다. TS3643는 비교 기준으로만 남긴다. AliExpress 일정은 사용자 수용 조건이며 소켓 사양은 미확인이다.
- 차단은 NKK S1A, 퓨즈홀더는 BK/HHC-R, 헤드 시험 퓨즈는 0287002.PXCN 2A로 선정한다.
- 분사 전에 **헤드 대신 저항**을 연결한다. 이 시험은 FFC나 카트리지가 없어도 먼저 할 수 있다.
- 외부18V 경로가 공개된 보드를 선정했다. 수령한 보드의 모델·E1 정격·실물 연결을 대조하기 전에는 통전하지 않는다. 첫 전기 시험은 헤드 없이 5V에서 한다.

이번 목록은 부품 선정을 진전시킨 문서다. FFC 배송 확정, 실물 헤드 핀 대응, 모듈의 18V 사용 검사, 실제 파형 시험까지 완료했다는 뜻은 아니다.

### FFC 조달 판단

TS3643의 `Type B`는 **해당 판매처의 1mm 면 옵션명**이다. 일반 FFC 케이블의 접점 동면/반대면 표기와 다르다. 2.54mm 핀헤더는 직접 납땜할 수 있다. Q2299A 리본이 커넥터에 들어가는 두께·접점 면·배선 방향은 실물 검사한다.

예비 조회 링크는 [Sharvi 16핀/1mm 납땜형](https://sharvielectronics.com/product/ffc-fpc-adapter-board-1mm-to-2.54mm-soldered-connector-16-pin/), [Uxcell a22011100ux0252](https://item.rakuten.co.jp/uxcelljapan/a22011100ux0252/)다. 둘 다 한국 배송과 목표일까지의 도착은 확인하지 못했다. 일본 대상 페이지의 납기를 한국 납기로 쓰지 않는다. 원칙적으로한국 도착 예정이11월7일 이내로 확인되지 않는FFC는일정용 주문을 보류한다. **AliExpress 배송은 사용자 수용 조건이라 이 배송 보류 원칙의 예외이며 Alibaba는 제외한다.** 소켓·리본·전기 정격 검사는 유지한다.

FFC-to-FFC 연장 보드, 0.5mm 옵션, IC만 달린 릴레이 보드, 단종 NHD-FFC16-1은 대체 구매하지 않는다. 이 표에서 한국 납기가 해결되었다고 표시한 FFC는 없다.

## 3. 배선의 핵심

근거: [MIKROE-233 제품표](https://www.mikroe.com/mikrodrive-board), [매뉴얼 p2](reference/mikrodrive-manual-v100.pdf), [원작 C6602 분사 회로](https://homofaciens.de/technics-machines-printhead-hp6602_en.htm).

**기존 MCD의 JP 번호와 좌우 방향은 사용하지 않는다.** ULN2803은 입력 HIGH일 때 출력을 GND로 당기는 부품이며 별도 논리 VCC가 없다. CN9의VCC는 사용하지 않고 J1은VCC-EXT로 선택한다. 보드 내장 E1 220µF와COM은부하 전원에 연결된다.

외부DC9~32V 제품표와 외부전원 선택 회로가18V 선정 근거다. 매뉴얼의95V/ULN2804 표기와 제품표의AC 입력 설명은 회로와 일관되지 않아 설계값으로 쓰지 않는다. 실제 보드가ULN2803 계열·25V 이상E1·공개회로와 다른 경우 멈춘다. 납품 불일치를 콘덴서만 바꾸어 임의 해결하지 않는다. 실제 분사 파형 검사는 별도다.

### 모듈 두 장에 공통으로 적용

| 위치/단자 이름 | 연결 | 주의 |
| --- | --- | --- |
| CN10 VCC-EXT | 외부 부하 전원 +LOAD | 첫 저항 시험5V, 이후18V. 동시에 연결 금지 |
| CN10 GND | 부하 전원 - | Uno GND와 공통 기준점 |
| J1 | VCC-EXT 쪽으로 연결 | VCC 쪽 연결 금지 |
| CN9 VCC | 미연결·절연 | Uno5V를 여기에 추가하지 않음 |
| CN9 GND | Uno GND | 신호 기준 |
| CN1~CN8 VCC-DRIVE | 부하 + | 싱크 출력이 아님 |
| CN1~CN8 DRV0~DRV7 | 해당 노즐 반환선/시험 부하 | 입력 HIGH일 때 GND로 당김 |

단자 **이름**이 기준이다. 매뉴얼의 CN9 그림은 왼쪽 D0/D2/D4/D6/VCC, 오른쪽 D1/D3/D5/D7/GND 순서지만 보는 면에 따라 반전될 수 있다. CN9 입력을 ULN 핀1~8까지 무전원 연속성으로 추적한다. GND는ULN9, COM은ULN10, DRIVE0~7는ULN18~11이다. 임의IDC 핀번호를 이 표에 덧붙이지 않는다.

### 신호 배정

U1/U2는 구매할 두 보드의 라벨이고 N0~N11은 논리 노즐 번호다. 실제 리본 핀/노즐 순서는 [접점표](HEAD_CONTACT_v1_2026-10-12.md)로 수령 검사한다. Uno D0/D1은USB 시리얼, D13은부팅LED 때문에 사용하지 않는다.

U2 CN9의D4~D7는GND로 고정하고 CN5~CN8 출력은 비워 절연한다. 사용 입력12개에 각각10kΩ 풀다운을 둔다. 사진의 CN9는암소켓이므로 A6 기존수헤더를 잘라끼우고 암-암 E-43으로 연결·당김방지한다. 풀다운 기판의GND는공통이다. 풀다운은 코드가 계속 HIGH를 출력하는 사고를 막지 못한다.

DFR0224의 단자 이름을 따라 연결한다. 단자 하나에 여러 선·저항을 억지로 넣지 않고, 풀다운 기판에서 분기한다. FFC의 헤드 전류 경로는 암-암 점퍼가 아니라 짧은22AWG 전선을 기판에 납땜하고 고정한다. 이동축 조립 뒤에는 실제 가동 케이블 길이로 파형을 다시 검사한다.

### 저항 시험 연결

```text
USB 전원 -----------------> Uno R3 + DFR0224
                              | D2 등, 10k 풀다운 포함
                              v
                           U1/U2 입력

시험용 부하 전원 + --> 퓨즈2A --> S1A 스위치 --> +LOAD
                                                  |
                       +--------------------------+--> U1 CN10 VCC-EXT
                       |                          +--> U2 CN10 VCC-EXT
                       |
                       +--> [150Ω/3W 두 개 병렬] --> 검사할 DRIVE 출력
                       |
                       +--> [10kΩ/1/4W 방전 저항] --> GND

시험용 부하 전원 - -------------------------------> GND
Uno GND / U1·U2 CN10 GND / CN9 GND --------------> GND

U1/U2 J1: VCC-EXT 선택, CN9 VCC: 미연결
```

헤드·FFC는 이 저항 시험 중 연결하지 않는다. 처음에는 **18V 어댑터를 완전히 분리**하고 USB로 전원을 받는 Uno의5V를 시험용 부하 전원 +로 사용한다. 한 번에 한 채널의75Ω 부하만 검사하므로 부하 전류는 약67mA다. Uno의 I/O 핀으로 부하 전원을 공급하지 않는다. USB 전류 여유가 없는 허브를 사용하지 않는다.

18V 시험으로 넘어갈 때는 전원을 모두 끄고 **Uno5V → +LOAD 연결선을 제거**한 다음18V 어댑터로 바꾼다. CN9 VCC는 계속 미연결이다. 실제 헤드 단계에서는 저항 부하를 제거하고, 검사로 확인한 리본 공통 전원과12개 노즐 반환선을 연결한다. **FFC1~16번의 최종 배정표는 실물 접점 검사 전 미완성**이며 이 표에서 임의로 채우지 않는다.

75Ω은 실제 카트리지의 내부 저항을 주장하는 값이 아니라 시험용 저항이다. 18V에서 최대0.24A, 연속4.32W, 저항 한 개당2.16W다. 두 저항을 서로 떨어뜨리고 공기가 통하도록 고정한다. 짧은 시험만 하고 열을 확인한다. 저항 시험은 실제 헤드의 전기·분사 특성을 재현하거나 보증하지 않는다.

10kΩ 방전 저항은 **스위치 이후 +LOAD-GND**에 둔다. 전원 차단 후에도 E1에 전압이 남을 수 있다. 30초 기다린 뒤 멀티미터로1V 미만인지 확인하고 배선을 바꾼다. 기다린 시간만으로 방전을 가정하지 않고 콘덴서를 금속으로 단락시키지 않는다.

## 4. 수령·조립 순서

1. **무전원 검사:** 모듈 모델·단자 이름·J1·E1 정격을 확인한다. 테스터로 단락과 연결을 확인하고 사진을 남긴다. FFC는 리본 접점부터 DIP 패드까지1:1 대응과 인접 단락을 검사한다. 리본 폭으로 접점 방향을 추측하지 않는다.
2. **5V 저항 시험:** 헤드와18V 어댑터를 분리한다. 부팅·리셋·USB 재연결 때12개 입력이 LOW인지 검사한다. 준비된 시험 코드로 한 채널씩 입력/출력 펄스를 측정한다. 원작 코드를 그대로 업로드하지 않는다.
3. **18V 수령 대조:** MIKROE-233 모델·ULN2803 계열·E1 최소25V·CN10/J1과 실제출력 경로를 확인한다. E1이16V거나 공개회로와 다르면 통전하지 않고 불일치품으로 처리한다. 기존 MCD 개조용 콘덴서는 주문하지 않는다.
4. **18V 저항 파형:** Uno5V 부하 연결을 제거한다. USB 연결과 LOW 초기화를 확인한 뒤 S1A를 켠다. 오실로스코프로 실제 출력의 펄스 길이·전압·부팅/정지 상태를 검사한다. 로직 분석기만으로18V 출력 상태를 확인하지 않는다.
5. **고정 헤드 점 시험:** 전원을 끄고 방전을 확인한 뒤에만 카트리지를 연결한다. 승인된 시험 코드에서 한 번에 한 노즐, 짧은 단발 분사부터 시작한다. 펌웨어 업로드·리셋·배선 변경 전에는 반드시 S1A를 끈다. 점 위치·누락·번짐을 기록한다.

[원작 실험](https://homofaciens.de/technics-machines-printhead-hp6602_en.htm)의18V·약3µs는 참고 출발점이지 HP 보증 규격이 아니다. USB 패킷 타이밍이나 `analogWrite()` PWM으로 분사 시간을 만들지 않는다. 시험 펌웨어는 후속 단계에서 핀 배정·최대 펄스·재분사 간격·정지 처리를 맞춰 작성한다.

오실로스코프는 공용/대여를 우선한다. 최소20MHz급,10× 프로브로3µs 펄스 형태와 출력 전압을 볼 수 있어야 한다. 접지 클립은 공통 GND에만 연결하고 +18V나 DRIVE 출력에 연결하지 않는다. 연결할 전원이 절연된 밀폐형 어댑터인지 확인한다. 멀티미터만 있으면 연속성·극성 검사는 가능하지만 **실제 카트리지 분사 시험은 아직 진행하지 않는다.**

## 5. 조립 부담과 보호의 한계

이미 조립된 부분은 Uno·실드·드라이버 모듈·전원 어댑터·DC 잭 케이블·퓨즈홀더다. 남는 작업은 신호선 라벨링, 풀다운 기판, FFC 굵은 피치 쪽 연결, 스위치 러그 납땜·절연, 고정이다. **완전 무납땜 레고 키트는 아니다.** 노출220V 배선, 승압기 조정,12채널 트랜지스터 회로의 직접 조립은 이번 구성에서 제외한다.

WAGO 한 개 안의3구는 모두 연결된다. +와-를 같은 WAGO에 넣으면 단락이다. 극성별로 따로 라벨링한다. 28AWG 신호 점퍼·부품 다리를 WAGO에 억지로 넣지 않고 허용 굵기의 전선 꼬리로 연결한다. 납으로 두껍게 만든 끝단을 나사 압착부에 넣지 않는다. 선 고정과 당김 방지는 필요하다.

2A 퓨즈는 전원선 단락 보호용이다. **노즐을 태우는 긴 펄스를 막는 장치가 아니다.** S1A도 사람이 끄는 스위치일 뿐 자동 인터락·안전 인증 비상정지가 아니다. 현재는 사람이 지켜보는 시험용 구성이며 무인 전시 승인 회로가 아니다. 이후 전시 단계에는 부팅·통신 끊김·펌웨어 고장 시 분사 차단을 별도로 검증한다.

## 6. 납기와 다음 작업

A5는DigiKey 재고4개·한국 일반 배송3~4일 표시를 확인했다. 필요2개이며 제조사 직판 품절과 구분한다. 국내 DFR0224 준비기간은 기존4~5일 표시다. DigiKey에서 여러 선정 부품의 재고를 확인했지만 캐시 값일 수 있고 예약 재고는 아니다. 실제 결제 화면의 출고 주체·재고·한국 도착 예정으로 최종 판단한다. 제조사 표준 리드타임은 **품절 후 새 생산 대기기간**과 구분해서 읽는다.

Q2299A의 FedEx Express1~3일은 사용자 확인 운송 정보다. 업체 출고 준비와 통관을 포함한 도착 보증은 아니다. TS3643의10월13일은 과거 조회의 입고 예정일이며 현재 우선 후보가 아니다. AliExpress 배송은 사용자가 수용했으므로 FFC의 남은 과제는 같은 배송 질문이 아니라 소켓 사양과 무전원 대응 검사다.

I4와 모터24V 연결표는 이미 작성했다. A5의 구매 설계는 외부전원 모듈로 변경했으며, 다음 구매 준비는 기계부 체결·배선·예산 통합이다. 고장 시 분사 자동 차단은 전시 단계의 후속 작업이며, 모듈 구매 가능 여부와 전시용 적합성은 구분한다. 이 문서의 USB·헤드 부품으로 I4를 대체하지 않는다. 주문·공급처 연락·펌웨어 업로드·실물 통전은 하지 않았다.

# 기계부 배치와 제작 조건

2026-10-12. [v21 재료표](BOM_v21_2026-10-12.md)의 D/E/F/P 항목에 적용한다. **아래 길이는297mm 롤 구성의 명목 배치이며 실측 전 절단 승인표가 아니다.** 원작 부품의 치수, 새 배치의 목표치, 수령 후 확정할 치수를 구분한다. P8 금속 지지대를 선정하고 파이프 간섭을 수정했으며, 낮은 프레임에 맞는 P3 가이드를 새로 작성했다. P9·공급 롤·인쇄판·최종 체결재 마감은 남아 있다.

### 프레임과 인쇄판

외부600×440 / 내부440×400, P8 기둥X±170과 기존 레일 방향을 유지한다. 앞뒤 급지 축의 명목 Y는±130, 가운데 가로 파이프는Y0이다. P9 금속판은 X±140/Y±210에 놓는다. 원작P6 반쪽의 실제 STL 외형40×40×9.7을 기준으로 모서리 안쪽 경계X±182.2를 계산했고, P9 판 가장자리X±170과12.2mm 간격을 남겼다. 기존X±180 배치를 최종 드릴 위치로 사용하지 않는다.

인쇄판은 **300×180×3mm**로 정한다. 종이297mm를 받치면서 P8 기둥 안쪽X±160까지10mm를 남긴다.360mm 인쇄판은 기둥과 겹치므로 제외한다. [P12 시험 STL](cad/P12_platen_saddle_trial.stl)2개를 X±120/Y0의 가운데 파이프에 고정한다. 부품 외형40×40×48.5, 파이프 채널15.4, 파이프 윗면부터 받침 윗면33.5mm다. 기존 낮은 프레임의 파이프 윗면Z38 +받침33.5 +판3 = 초기 종이면Z74.5mm다. 실제 피복 롤러 반지름에 맞춰 높이는 첫 시험에서 조정한다.

P12마다 수평 M4×50 볼트2개·1mm 이하 평와셔2개씩·M4 일반 너트, 파이프 내부 금속 칼라KNCLM4-8-12를 쓴다. 인쇄판은P12마다 **접시머리 M4×60 2개**로 관통 고정한다. 인쇄판 구멍은 (±120,±16), Ø4.5 네 곳이며 윗면에90도 카운터싱크를 가공해 실제 볼트 머리와 평탄하게 맞춘다. 볼트 머리와 와셔를 종이 아래로 돌출시키지 않는다. 아래쪽에0.8mm 평와셔와 높이3.2mm M4 너트를 넣는다. 명목 길이 적층은48.5+3+0.8+3.2=55.5mm라60mm 볼트가4.5mm 남는다. 종이 없이 자/손으로 평탄함을 확인한 뒤 급지한다.

파이프 절단은 옆400×2/가로410×3이다. 원작 [frame_link.stl](reference/worldprinter/frame_link.stl)은 한 반쪽이므로 네 코너에 **8개**를 맞대어 쓴다. 코너 한 쌍의 기존3홀에M3×30 3개를 넣고, 실제 파이프를 관통하는 두 곳에는OD6/ID3.2/길이12 칼라를 넣는다. 가운데 파이프 양끝은 [P14 T형 반쪽](cad/P14_centre_pipe_tee_half_trial.stl)을 **4개**, 두 쌍으로 사용한다. 한 T연결당M3×30 3개와동일 금속 칼라3개다. 측면 파이프는Y방향으로 관통하고 가운데 파이프는X방향으로 들어간다. 좌우는Z축180도 회전, 위·아래는X축180도 회전으로 배치한다. 새로운 구조를 원작P6가 이미 포함한 것으로 계산하지 않는다.

P9는 금속판60×50×3 네 개와 기존 출력 캡4개다. 내부 칼라는 **KNCLM5-8-12**, 제조사 범위OD7.8~8.0/ID5.1~5.3/L11.9~12.0mm를 따른다. 시험 모델 내경은 범위 중간5.2로 갱신했다. 프로파일 쪽은M5×10 8개에각SPWF5 두 개를 머리 아래에 넣어 판 밑 돌출을5mm로 줄인다. 파이프 관통은 **M5×35 4개**, 와셔 위/아래1개씩, **SLBNR5 4mm 일반 너트2개씩**으로 바꾼다. 나일론 너트의 높이·조달 불확실성을 없애고 공개된 일반 너트 높이로 맞춘다. 명목 적층3+15+3+2+8=31mm, 끝단4mm다. 두 너트는 스패너로 서로 잠그며 출력 캡을 강하게 눌러 잠그지 않는다.

### 공급 롤과 원자재

공급 롤은 프레임 뒤의 **별도600×200×3mm 받침판**에 둔다. [P13 시험 STL](cad/P13_roll_stand_trial.stl)2개를 X±200에 고정한다. 발60×120/전체 높이110/축 중심100mm다. 받침판의구멍은 X=-220/-180/+180/+220와Y±45의8곳, 모두Ø4.5다. M4×20/0.8mm 와셔 위·아래/일반M4너트로고정한다. 적층8+3+1.6+3.2=15.8mm, 끝단4.2mm다. 받침을 탁자에고정하고, 부품의Y방향구멍을지나는4.8mm 폭 타이로 M10 축이위로들리지 않도록각1곳 묶는다. 출력물에나사산을만들거나접착제로만고정하지 않는다.

M10 공급축은 명목 **520mm**다. 롤 폭297, 받침 안쪽X±170,2mm 와셔+8mm 너트2개를 넣고도 플랜지와3.5mm 명목 간격이 남는다. 바깥쪽은받침 끝230+와셔2+너트16=248로축끝260까지12mm가남는다. 추가일반M10너트8/평와셔4가필요하다. 기존6200ZZ 지관지지2와원작P5 부품/캡2를사용하고93mm `paper_position.stl`은사용하지 않는다. 베어링내륜고정용기존40너트·18짧은간격재·2긴칼라는그대로이므로총M10너트48/일반와셔6다.

최대 롤외경은이받침의명목수용한도 **170mm**로제한한다.축중심100−반지름85=판위여유15mm다. H1 롤의실제외경은아직실측하지 않았으며170mm보다큰롤을억지로끼우지 않는다. 롤의지관지지플랜지·중심·공급축회전과자유이송을무전원으로확인한다.

금속판 원자재는 [에이스코/11번가1099863743](https://www.11st.co.kr/products/1099863743)의 **3T×400×600 1장**이다. 표시43,030원, 판매수량선택과국내배송비안내는있지만구체수령일은표시하지않았다. 화우/세창 사이트는판재가격문의가필요하다고공지해이안의직접주문처로사용하지 않는다. 판한장에서300×180 인쇄판1/600×200 롤판1/60×50 P9판4를 [재단도](cad/mechanical_layout_v22.svg)대로자른다. 톱날손실3mm를반영했고P9용50×3 평철을추가구매하지 않는다. 전용금속톱·클램프·드릴·카운터싱크·줄작업이필요하다. 치수주문제작·용접·레이저가공은전제하지 않는다.

| 400mm | 300mm | 50mm | 22.5mm | 확대안, 미채택 |
| 400mm | 320mm | 40mm | 12.5mm | 확대안, 미채택 |

종이 여백은 `(용지 폭-인쇄 폭)/2`, 이동 잔여는 `(345-인쇄 폭)/2`다. 종이가 넓어도 전폭을 인쇄할 필요는 없지만, 큰 종이를 지지하고 양쪽 가장자리를 누를 수 있도록 급지 베어링·롤 지지·인쇄판의 폭과 위치를 바꿔야 한다. 내부 폭440mm에400mm 종이를 놓으면 명목 잔여는한쪽20mm뿐이며 그 공간에 고정부까지 들어간다는 증거는 없다. 외부 받침600mm를 반드시 키워야 한다고 단정하지는 않지만 기존 도면을 그대로 승인할 수도 없다.

현재600 x440mm는 **받침의 평면 치수**다. 모터·케이블·공급 롤·출력물 받침까지 포함한 완성 외형이나 설치 공간 치수가 아니다. 전체 높이도 아직 확정하지 않았다. 원작 전체를 축소 복제하는 대신 원작의 급지 부품 치수와 선택한 기성 X축을 조합한다.

X는 종이 폭 방향, Y는 종이가 내려오는 방향, Z는 높이다. 앞뒤 급지 사이에서 헤드가 X 방향으로 움직인다. 공급 롤과 출력물 받침은 이동축에 매달지 않고 별도로 지지한다.

```text
상면, 치수 단위 mm

             수동 공급 롤 / M10 축
                       |
          +------------v-------------+
          |       뒤 급지 롤러       |
          |                          |
  X <-----|   500mm 벨트 축 + 헤드   |-----> X
          |       평탄 인쇄면        |
          |                          |
          |       앞 급지 롤러       |
          +------------v-------------+
                       |
                 출력물 받침

외부 2020 받침 목표: X600 x Y440
내부 15mm 파이프 목표: X440 x Y400
종이: X297 / 인쇄 영역 목표: X270
```

600mm 받침 폭이 모터까지 포함한 실제 축 외형을 수용하는지는 수령 후 대조한다. 500mm는 레일 길이이지 조립 전체 길이 또는 유효 이동거리가 아니다. 받침을 벗어나거나 헤드 높이 조절이 막히면 프레임 가안을 수정하고, 조립품을 억지로 밀어 넣지 않는다.

### 접촉 베어링과270mm 인쇄폭의 계산

아래는6200ZZ의명목폭9mm를종이폭 방향의접촉폭으로보수적으로잡은배치 계산이다. 실제고정부·와셔·베어링 챔퍼와종이쏠림을측정한값은아니다. 종이 왼쪽을X=0, 오른쪽을X=297로잡는다.

| 구간 | 계산 목표, mm |
| --- | --- |
| 인쇄영역 | X=13.5~283.5, 폭270 |
| 왼쪽 접촉 베어링 | 중심6.75, 폭9 → X=2.25~11.25 |
| 오른쪽 접촉 베어링 | 중심290.25, 폭9 → X=285.75~294.75 |

| 가장자리여유1mm를남기는횡방향변동목표 | 2.25-1=1.25 이하 |

앞뒤닙에각각왼쪽/오른쪽접촉 베어링을배치하는검토값이다. 마찰면·가드·와셔의바깥지름이종이나잉크에닿는지확인하고, 상부축에서베어링이옆으로이동하지 않도록지지한다. 베어링내륜 고정과외륜 회전을구분한다. 잉크가닿는범위에서누르거나종이실측쏠림이허용여유를넘으면인쇄폭·베어링위치·가이드를다시정한다. 1.25mm는시험목표이며자체위치제어 성능을보증하지 않는다.

X축의보수적이동량345mm와인쇄폭270mm의차이는75mm다. 중심배치의수치상여유는좌우37.5mm지만원점센서·헤드오프셋·케이블·감속공간을뺀사용가능여유는실측해야 한다. 이계산은캐리지/고정도면·최종절단표를대체하지 않는다.

## 4. 기어 수량 수정

[gears.stl](reference/worldprinter/gears.stl) 안에는 **25T 소기어1개 +60T 대기어1개**가 있다. 파일을 **2번 출력**하면 앞뒤 급지에 필요한 소기어2개 +대기어2개가 된다. 원작 SCAD의 별도70T 뒤 급지 기어는 주석 처리되어 있고 이 STL에는 없다.

이번 기준은 앞뒤 모두60:25 감속비다. 원작의 뒤70:25 값을 그대로 사용하는 펌웨어는 맞지 않는다. 앞뒤 롤러의 실제 `mm/step`은 각각 보정한다. 같은 기어비가 같은 종이 이동량을 보장하지 않는다.

25T의 축 구멍은5.2mm,60T는10mm다. 5mm 모터축의 소기어는 원작의 M3 횡방향 볼트·너트 고정 구조를 사용하며 마찰 끼움만으로 고정하지 않는다. 정확한 볼트 길이는 출력 후 허브·축 평면과 대조한다. 원작 치형은 일반 시판 기어의 모듈 규격으로 확인되지 않았으므로 임의의 금속 기어 한쪽만 섞지 않는다.

### P2 파이프와 P3 연결 상세

위 미완 항목 중 P3의 설치 방향과 명목 적층을 다음으로 구체화했다. [단면 SVG](cad/feed_mount_trial.svg), [미리보기](cad/feed_mount_trial.png), [치수 검사](cad/check_feed_mount_trial.py)는 전체 조립 설명서가 아닌 연결 상세다. 원작 부품 치수로 구성한 이번 프로젝트의 배치이며 원작이 제공한 전체 조립도라고 주장하지 않는다.

P2의 베어링 보스·파이프 채널이 있는 면을 종이 쪽으로 향하게 한다. P3의 평평한 뒷면은 **파이프 안쪽 면**에 붙이고 슬롯이 종이 쪽으로 열리게 한다. P3를 P2 밑판 바로 위에 넣거나 파이프와 같은 공간에 겹치지 않는다.

| 연결 | 명목 적층과 볼트 | 사용 수량 | 금속 간격재 |
| --- | --- | ---: | --- |
| P2 채널과 파이프, 기존 횡방향2홀 | 출력벽2 + 채널15.4 + 출력벽2 =19.4mm. M3×30 / 와셔2 / 일반 너트1 | 4받침×2 =8세트 | 파이프 속 OD6 / ID3.2 / 길이12mm, 8개 |
| P3와 파이프와 P2, 기존15mm 피치2홀 | P2 밑판2 + 실제 파이프15 + P3 15 =32mm. M3×40 / 와셔2 / 일반 너트1 | 4받침×2 =8세트 | 같은 규격8개. 횡방향 간격재와 별도 |

이번 두 연결의 합계는 **M3×30 8개, M3×40 8개, 너트16개, 와셔32개, 금속 간격재16개**다. 위 P2/P5 덮개22세트까지 합치면 M3×25 16개 / ×30 14개 / ×40 8개 / 너트38개 / 와셔76개다. 모터·헤드·프레임·M10 체결은 이 합계 밖이다.

와셔를 각1mm 이하, 일반 M3 너트를 높이3mm 이하로 제한하면 끝단 잔여는 ×30에서5.6mm, ×40에서3mm다. P2 원본의 파이프 횡홀은 로컬Y=±38이고 P3 체결홀은17/32이므로 같은 구멍으로 세지 않는다. P3의 로컬X=-8인 홀을 P2의X=-25.5에 맞추려면 P3를X=-17.5만큼 옮긴다. 로컬Z 방향 적층은 P2 0~2 / 파이프2~17 / P3 17~32다. 위치값은 원본 개별 부품 좌표이며 프린터 전체 좌표와 다르다.

파이프 양면의 관통홀은 받침을 대고 위치를 옮겨 표시한 뒤 가공한다. 내부 간격재는 파이프 끝이 열린 상태에서 먼저 넣고 볼트로 위치를 잡는다. 명목 내폭은 `15-1.5×2=12mm`지만 실제 내폭·내부 모서리·간격재 공차를 대조한다. 억지로 끼우거나 짧은 간격재의 틈을 강한 조임으로 메우지 않는다. P3 슬롯 입구와 볼트 머리/와셔, 상부 축의 삽입·탈거 경로는 첫1개 시험 조립에서 확인한다. 이 단면도는 볼트 머리를 포함한 전체 간섭 검증은 아니다.

간격재 조달 후보는 [Würth963120042 / DigiKey732-963120042-ND](https://www.digikey.kr/ko/products/detail/w%C3%BCrth-elektronik/963120042/9488477)다. 판매 페이지가 OD6/ID3.2/L12의 니켈 도금 황동 무나사형으로 명시한다. 2026-10-12 직접 페이지의 재고1,122개·10개 구간923원/개를 확인했으며16개 단순 계산은14,768원(세금·배송 별도)이다. 검색 결과의 이전1,098원/재고1,335와 섞지 않는다. 한국 페이지지만 국내 창고 재고로 확인한 것은 아니다. 일반 한국 배송3~4일 안내는 목표 일정에 맞는 후보 근거이지 개별 도착 보증은 아니다. 제조사26주 리드타임은 재고품 수령일과 구분한다. 연결된 제조사 PDF는 접근 실패로 공차·압축 하중 정격을 읽지 못했으므로 이 후보만으로 강도를 인증하지 않는다. 나사산 있는 M3 스탠드오프나 나일론 부품으로 바꾸지 않는다.

### 상부 축 길이와 M10 적층의 경계

이 배치에서440mm 외폭의 파이프 양 바깥면은 전체X=±220이고 P2 밑판 바깥면은±222다. P3는파이프 안쪽 면±205부터 안쪽으로15mm 돌출한다. P3의2mm 뒷벽 때문에 슬롯의 막힌 면은±203, 입구는±190이다. 따라서 상부400mm 봉을 중심에 놓으면 끝은±200으로 **한쪽 뒷벽 여유3mm, 슬롯 물림10mm**가 된다. 495mm 상부 봉은 막힌 면 사이406mm보다 길어 이 배치에 맞지 않는다.

주문은 M10 원자재로 준비하고 상부2본의 최종 길이는 조립된 막힌 면 사이 거리에서 총6mm 여유를 빼서 잡는다. 내폭을 실제로 확인하기 전에400mm 선절단 서비스를 주문하지 않는다. 상부 축은 종이를 누르는 베어링과 하부 롤러에 얹히므로 슬롯 안에서 높이가 움직여야 하며, 축 끝을 P3에 강하게 죄어 고정하지 않는다.

하부 축은 상부와 달리 베어링을 관통하고 기어를 고정해야 하므로400mm를 공용으로 쓰지 않는다. 원본 `gear()`의 기본높이5mm가 아니라 실제 호출값 **60T 두께9mm / 25T 치형10mm + 허브8mm**를 적층 계산에 쓴다. v20에서는 축 도면이 공개된17HS19-1684S1로 B2 두 개를 바꾸고 아래 하부 적층을 선정했다. B1 X축 동봉 모터는 바꾸지 않는다.

M10 일반 평와셔를 베어링 측면에 바로 대어 실드를 누르는 구성은 채택하지 않는다. 예를 들어 [NSK6200ZZ](https://www.nsk.com/engineering/6200zz-apn.html)는 내륜 받침 지름14~16mm를 제시한다. 이는 내경10/외경30/폭9가 같아도 받침 형상을 따로 봐야 한다는 근거이며, 현재 KBC 후보의 허용값으로 그대로 전용하지 않는다. M10 너트·간격재 수량은 아래 적층과E3에 반영했다.

추가로 [KBC 카탈로그 사본](https://btcbearing.com/wp-content/uploads/2019/01/kbc-catalogue.pdf)의140~141쪽을 렌더해 대조했다. 6200ZZ 행은 d10/D30/B9mm, 축 받침 지름 Ds 최소14mm, 모서리 R 최대0.6mm다. 이 표에는 축 받침 지름의 최대값이 없으므로 NSK의16mm를 KBC 보증값으로 옮기지 않는다. 이는 내륜만 받치는 간격재 선정 근거이며 실제 실드 비접촉·회전 저항 검사를 대체하지 않는다.

### 하부 급지축과 기어 적층

오른쪽 구동부의 베어링 바깥 면을 `u=0`, 프레임 밖으로 나가는 방향을 `+u`로 둔다. 전체 좌표에서는 이 면이X=219.9mm인 명목 배치다. P2 밑판 바깥 면은u=2.1, 모터 앞면은u=0.1이다. 앞뒤 급지부에 같은 적층을 사용하고 반대쪽 배치는 좌우를 뒤집는다.

| 순서 | u 구간(mm) | 부품 |
| --- | ---: | --- |
| 베어링 | -9~0 | 6200ZZ |
| 바깥 간격 | 0~12 | KNCLM10-15-12 금속 칼라 |
| 큰 기어 | 12~21 | 원작60T, 두께9 |
| 와셔 | 21~23 | 일반 M10 평와셔, 두께2 이하 |
| 잠금 | 23~39 | 일반 M10 너트2개, 각 높이8 이하 |
| 축 끝 | 45.1 | 530mm 봉의X=265 끝. 마지막 너트 뒤 명목6.1mm |

소기어는 허브를 안쪽으로 두고 u=3.5~11.5, 치형을11.5~21.5로 배치한다. 따라서 큰 기어9mm 전부가 소기어10mm 치폭 안에 들어간다. 모터 축의 최소 끝은 `0.1+23=23.1mm`여서 소기어 바깥면 뒤로1.6mm가 남는다. 허브와 P2 사이 여유는1.4mm다. 원작 치형을 그대로 쓰고 모터 슬롯에서 백래시를 맞춘다. 이1차원 계산은 실제 치형·볼트머리·가드 간섭이나 출력 공차 검증이 아니다.

반대쪽 베어링 면에는두께3mm·OD15인 WSSM15-10-3을 넣고 일반 너트2개를 서로 잠근다. 일반 너트/와셔를 베어링 실드에 직접 대지 않는다. 베어링10개의20면 중 구동측2면은12mm 칼라, 나머지18면은3mm 간격재다. 합계 **칼라2, 짧은 간격재18, M10 너트40, 기어 바깥 평와셔2**다. 부품별 구매 단위와 가격은 [v20 선정표](SELECTION_v20_2026-10-12.md)를 따른다.

축 양쪽의 너트를 조여 프레임이나 베어링 외륜을 서로 당기지 않는다. 각 내륜만 고정하고, 출력 캡을 체결한 뒤 손으로 한 바퀴 돌려 걸림·실드 접촉·축방향 압박을 검사한다. 출력물 크리프로 기어가 헛돌지 않는지도 반복 시험한다. 강한 조임으로 문제를 감추지 않는다.

모터 고정은 M3×6과두께0.5mm 평와셔 각8개로, P2 두께2mm를 통과해 나사 물림3.5mm를 목표로 한다. 최소4.5mm 탭 깊이보다1mm 짧다. 소기어의 원작 횡방향 너트 홈에는 M3 너트와 M3×16을 각2개씩 시험 선정한다. 나사 끝이 D면에 닿도록 조정하고 머리 돌출·주변 간섭을 실측한다. 이 M3 부품은E3의 M10 수량에 중복 포함하지 않고 최종D4에 합산한다.

하부530mm 두 개와 상부400mm 두 개는1m 봉 두 본에서 각각 `530+400+톱날손실6=936mm`로 나눌 수 있다. 세 번째1m 봉은 공급축용이다. **530/400은 선절단 주문값이 아니라 조립 실측의 기준값**이며 공급축을495mm로 자동 절단하지 않는다.

## 7. 제작 승인 조건

1. 캐리지와 홀더 치수를 대조하고 P1/P8/P9 도면을 완성한다.
2. 공급 롤의 지관·외경, 축 적층, 실제 이동량으로 배치와 절단표를 갱신한다.
3. P2/P3/P6/P7의 작은 시험 출력에서 끼움·맞물림을 확인한다.
4. 금속 하중 경로·볼트 적층과 케이블/노즐 간섭을 확인한 뒤 절단·전체 출력을 승인한다.

## 8. P9 시험 고정부: 금속 받침 + 출력 캡

기존 외부600 x440 / 내부440 x400 가안에서 앞뒤2020 부재의 중심선은Y=+/-210, 내부15mm 가로 파이프의 중심선은Y=+/-192.5다. 두 중심선의 차이17.5mm를 연결하는 **시험 설계**다. P9 위치는 앞뒤 부재의X=+/-180mm를 가정한다. 이는 최종 배치나 주문 치수 승인으로 채택한 값이 아니다.

제조사 [VS20-1 설명](https://bulkman3d.com/product/vs20-1/)은 작은 캐리지를 **레일20mm 면 전용**으로 명시한다. ### 명목 배치와 체결 위치

외부600 x440 가안의 안쪽 폭은560이다. 가로보는X방향560mm, 중심Y35, Z0~20에 두고, 기둥 중심X=-170/+170, Y35, Z20~170으로 잡았다. 기둥 안쪽 경계X±160은 종이 경계±148.5 밖이다. 발 브래킷 바깥±200과 파이프 안쪽±205 사이 명목5mm, 가로보 윗면Z20과 파이프 밑면Z23 사이 명목3mm를 남긴다. 이전±210 기둥은 파이프와 겹쳐 폐기했다. 150mm 기둥 길이는 프린터 전체 높이가 아니다.

X축2040은 앞면높이20/깊이40, 앞Y=-20/뒤Y20, Z80~100이다. HBLSS5는 폭14/다리20/두께3/Ø5.5/다리별 홀오프셋10·15다. 기둥 양쪽의 레일 체결점은 **(-190,90), (-150,90), (150,90), (190,90)**이며 모두 뒤 한 홈Z90에 있다. 새 드릴 구멍이 아닌T너트 위치다. 브래킷 외곽±200과 레일 끝±250의 명목 여유는50mm지만 끝판·풀리 실물 간섭 검사를 대신하지 않는다.

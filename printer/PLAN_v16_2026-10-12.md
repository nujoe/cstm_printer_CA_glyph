# WorldPrinter 기반 글리프 롤 프린터 계획 v16

2026-10-12. 기준: [재료표 v16](BOM_v16_2026-10-12.md), [선정 근거](SELECTION_v16_2026-10-12.md), [주문 준비 목록](ORDER_v1_2026-10-12.md), [헤드 접점표](HEAD_CONTACT_v1_2026-10-12.md), [기계부 조건](MECHANICAL_v1_2026-10-12.md). [이전 v15](PLAN_v15_2026-10-12.md)은 보존한다.

**방향은 Pi + Uno, C6602A, 소형 벨트 X축을 유지한다.** 3D 출력은 사용자가 직접 또는 제작 의뢰로 진행하고150,000원을 배정한다. 출력 업체·필라멘트 조사는 제외한다. 기존 Pi·전원·microSD는 디스플레이용으로 남기고 프린터 전용 Pi와 부속을 신규 구매한다. 모든 부품의 한국 도착일과 실제 헤드 핀 대응까지 확정된 것은 아니므로, 전체 일괄 주문 가능한 완성 키트로 표시하지 않는다.

같은 모델 또는 확인된 호환품의 국내 구매를 우선한다. 국내 판매처라도 해외 창고·수입 준비 상품은 [주문 준비 목록](ORDER_v1_2026-10-12.md)에서 별도로 경고한다. 날짜 미확인 상품을10월~11월초 도착 확정으로 표현하지 않는다.

AliExpress 배송 일정은 사용자가 수용했다. 이 경로의 후보는 배송 확인 부족만으로 제외하지 않고 옵션·정격·호환을 대조한다. Alibaba는 제외한다. 개별 도착일을 직접 검증한 것은 아니며 브라우저 접근 차단을 우회하지 않는다.

v10의 [헤드 시험](HEAD_TEST_v1_2026-10-11.md), v11의 [I4](I4_WIRING_v1_2026-10-12.md), v12의 [24V 독립 분배](MOTOR_POWER_v1_2026-10-12.md)를 유지한다. 기본 출력 차단·전원 분배는 설계이며 실물 파형·실제 소비전류·감속 전압·무인 전시 보호의 검증 완료가 아니다.

## 1. 만들 장치

- 일반 잉크젯 롤지에 흑백 글리프를 한 행씩 인쇄한다.
- 한 행을 인쇄한 뒤 기다렸다가 다음 행을 이어 찍는다. 커팅·강제 페이지 배출은 없다.
- 종이 폭 297mm, 인쇄 폭 약 270mm, 행당 글리프 10개를 설계 목표로 삼는다. 실제 폭·간격은 인쇄 시험 후 정한다.
- 프린터 전용 Pi 4 Model B 4GB를 신규 구매하고, 기계부는 볼트와 3D 출력 고정부 중심으로 조립한다.
- 노출된 220V 단자 배선·용접·맞춤 축 제작은 넣지 않는다. 3D 출력 부품에 한해 제작 의뢰가 가능하고 PCB/PCBA 의뢰는 계속 보류한다. 소량의 저전압 납땜과 드릴 가공은 남는다.

## 2. 기준 구성

```text
TouchDesigner / 메인 PC
    | 완성된 한 행의 흑백 이미지 + row_id
    v
프린터 전용 Raspberry Pi 4 4GB / 신규 구매
    | 저장·대기열·비트맵·모션
    |
    +-- USB 데이터 케이블 --> Uno R3 + DFR0224
    |                              |
    |                         MCD2803A-02 x 2
    |                              |
    |                         FFC-DIP 변환기판
    |                              |
    |                         Q2299A + C6602A
    |
    +-- 3.3V/5V 신호 연결부 I4 --> DM332T x 3
                                     |
                         X축 / 뒤 급지 / 앞 급지
```

USB는 Pi와 Uno 사이의 명령·응답 연결이다. Pi GPIO에 Uno의 5V 반환 신호를 연결하는 원작 방식은 쓰지 않는다. 이미지 전송과 노즐 펄스 생성은 구분하며, 짧은 분사 펄스는 Uno 안에서 만든다. 이 변경에는 나중에 통신·동기화 코드 수정이 필요하다.

Pi와 모터 드라이버 사이에는 여전히 I4가 필요하다. USB로 바꿨다고 모든 신호 전압 문제가 사라지는 것은 아니다.

### 디스플레이와 프린터 분리

- 메인 PC는 카메라·세그멘테이션·RGB·CA·글리프 생성을 맡는다. 프린터 Pi에는 완성된 행 이미지와 식별자만 보낸다.
- 기존 Pi·전원·microSD는 디스플레이 전용이다. 프린터용으로 재사용하거나 임시로 빼오지 않는다.
- 새 프린터 Pi 한 대가 저장·대기열·인쇄 데이터·모션을 맡고 Uno가 노즐 펄스를 만든다. 같은 프린터의 축과 헤드를 여러 Pi가 나눠 제어하지 않는다.
- 프린터 Pi에는 전시 브라우저·영상 재생·CA 계산을 올리지 않는다. 디스플레이 장치와 분리하는 목적은 작업 간 간섭을 줄이는 것이며 타이밍 안정성을 자동 보증하는 것은 아니다.
- 현재 기준은 Pi4 Model B 4GB다. Pi5로 바꾸면 GPIO·모션 라이브러리 호환 검토가 추가되므로 가격만 보고 변경하지 않는다. 본체·전원·microSD 합계250,000원을 가배정한다.
- Pi4의 연결·전원 기본 조건은 [공식 안내](https://www.raspberrypi.com/products/raspberry-pi-4-model-b/)를 따른다. 실제 GPIO 파형·축 이동·통신 중단·발열 시험은 남는다.

## 3. X축과 급지

### X축 선정

기준 상품은 [Bulk-Man V-Slot NEMA17 Linear Actuator Bundle](https://bulkman3d.com/product/v-slot-nema-17-linear-actuator/)의 **500mm 옵션**이다. 모터·레일·바퀴·벨트·풀리가 포함된 볼트 조립 키트이며, 조립 완료 스테이지는 아니다. 모터 드라이버는 별도다.

500mm는 레일 길이이다. 판매 페이지에 이동거리 설명이 서로 다르게 있어 설계에는 보수적인 약 345mm를 사용한다. 270mm 인쇄 영역과 끝단 여유를 배치하고, 조립 후 실측 이동량으로 원점·소프트 리미트를 정한다. 헤드 어댑터가 움직임을 더 제한할 수 있다.

기존 NEMA23·SFU1605·HB808C/HBT57·DM556 후보는 구매 기준에서 제외한다. 급지 모터 2개는 같은 판매처의 **N17SM-48-5 / 1.7A / 5mm 축**으로 선정한다. X축 동봉 모터의 상세 부품번호는 페이지에서 보증하지 않으므로 수령 라벨과 상전류를 확인한 뒤 드라이버 전류를 설정한다.

### 드라이버와 신호

세 축에 **DM332T 3개**를 사용한다. 모터용 24V와 논리 신호용 5V는 다른 전원이다. 모터 정격 상전류를 어댑터 입력 전류와 동일하게 계산하지 않으며, 드라이버의 peak/RMS 설정도 구별한다. [드라이버 설명서](https://www.omc-stepperonline.com/download/DM332T_user_manual.pdf)

I4의 기준 소자는 **SN74ACT244N**이다. Pi의 3.3V 신호를 받는 TTL 입력과 5V 출력 구동 능력이 선정 이유다. **SN74AHCT14N**은 ARM을 반전해 출력 허용핀 OE만 제어한다. 단순 I2C 레벨 변환기나 릴레이 보드로 대체하지 않는다. 완성 모듈이 아니라 소켓·저항·단자를 납땜하는 작은 저전압 기판이다. [TI ACT244](https://www.ti.com/lit/ds/symlink/sn74act244.pdf), [TI AHCT14](https://www.ti.com/lit/ds/symlink/sn74ahct14.pdf)

[I4 연결표](I4_WIRING_v1_2026-10-12.md)에 회로를 작성했다. Pi의 5V 한 곳에서 논리 IC와 드라이버 OPTO를 공급하고, 드라이버별 공통 양극 OPTO/PUL/DIR 3가닥을 사용한다. Pi GND를 드라이버의 모터 전원 GND에 추가 연결하지 않는다. ENA는 미연결이므로 ARM OFF도 모터 전원을 끄거나 유지 토크를 해제하지 않는다.

신호 대기 레벨은 HIGH이며, STEP와 DIR 준비 후 ARM을 켠다. 전원 고장 또는 소프트웨어 멈춤까지 자동 차단하는 회로는 아니다. 실물 검사와 원점·끝단 처리 코드가 준비되기 전 모터 통전을 진행하지 않는다.

G4는Panasonic AEQ10410 3개로 원점·끝단·정지 요청을 나누고COM/NC 접점을 사용한다. 3.3V·10k 풀업·1k 직렬 저항과BCM5/6/16 배정은 유지한다. 작은 핀형 스위치라 장착·누름부와 정지 코드는 남아 있다. [선정·가격·배송·시험 조건](G4_INPUTS_v1_2026-10-12.md)을 따른다. 전원 차단이나 안전 인증 비상정지로 사용하지 않는다.

### 종이 경로

```text
수동 공급 롤
    v
뒤 급지 롤러 한 쌍
    v
평탄한 인쇄 받침 <--- 벨트 X축의 헤드
    v
앞 급지 롤러 한 쌍
    v
느슨한 출력물 받침
```

앞뒤 급지 롤러의 실제 이동량을 각각 보정한다. 두 축을 같은 스텝 수로만 돌리면 지름 차이 때문에 종이를 당기거나 밀 수 있다. 롤의 무게와 출력물의 무게가 인쇄면에 직접 장력을 만들지 않게 배치한다.

급지 기어는 앞뒤 모두25T 모터 기어/60T 축 기어로 정한다. 확보한 원작 `gears.stl`에는 이 두 개만 있으므로 두 번 출력한다. 원작의 별도 뒤70T 가정을 쓰지 않고 실제 이동량을 각각 보정한다. [기어와 수량](MECHANICAL_v1_2026-10-12.md).

## 4. 분사부와 전원 간소화

| 부분 | 이번 구성 | 남는 작업 |
| --- | --- | --- |
| 카트리지 연결 | C6602A + Q2299A + 16핀 1mm FFC-DIP | 리본 삽입 두께·접점 면·핀 대응 검사 |
| Uno 연결 | R3 + DFR0224 단자 실드 | 신호선 끝단 처리·라벨링 |
| 분사 드라이버 | MCD2803A-02 2개, JP2 1-2 / JP3 pin9 미연결 | C1·단자 정격, 기본 OFF, 실제 펄스 시험 |
| 24V 입력 | GST120A24-P1M + 10-02245 + S1A + BK/HHC-R + 5A 퓨즈 | WAGO 극성별 독립 분배, 소비전류·감속 전압 시험 |
| 18V 입력 | GST60A18-P1J + Tensility 10-02247 + S1A + BK/HHC-R + 2A 퓨즈 | 헤드 분리 저항 시험, 극성 검사 |

Tensility 두 케이블은 DC 잭과 전선이 연결된 제품이므로 잭 납땜을 줄인다. 24V 쪽은 5.5×2.5mm, 18V 쪽은 5.5×2.1mm다. 치수 차이를 안전 장치로 믿지 말고 전압 라벨과 커버를 사용한다. 양극은 서로 연결하지 않는다. 어댑터는 제어함 밖에 두고 접지형 C13 완성 코드로 콘센트에 연결한다.

[모터24V 연결표](MOTOR_POWER_v1_2026-10-12.md)에 0287005.PXCN 5A 퓨즈, 모터용221-413 1개/221-415 2개, 고정 전원선30-00683 2m를 선정했다. C1/C3/C4는 교체하지 않는다. 24V/5A가 실제 세 축 부하를 감당하는지는 미검증이며 감속 시30V 상한도 확인해야 한다. GST120A의 음극-보호접지 연결 때문에 전체 장치의 완전 절연을 주장하지 않고 AC 접지를 제거하지 않는다.

MCD2803A-02의 부하 전원에 연결된 C1은 정격 전압이 자료에 없다. 18V를 넣기 전에 부품 표시를 확인하며, 교체가 필요할 때 사용할 220uF/35V 후보를 재료표에 둔다. 교체품의 리드 간격·외경도 확인해야 한다. ULN IC의 최대 정격만으로 모듈 전체를 18V용이라고 판단하지 않는다.

원작의 18V·짧은 펄스는 시험 출발점이다. 헤드가 빠진 상태에서 기본 OFF와 더미 부하 파형을 확인한 뒤 실제 분사를 시험한다. 전원 스위치만으로 펌웨어 오류의 장시간 분사를 막을 수 있다고 가정하지 않는다. [헤드 원작 자료](https://homofaciens.de/technics-machines-printhead-hp6602_en.htm)

이번 더미 부하는150Ω/3W 저항2개 병렬인75Ω이며 실제 헤드 저항을 주장하는 값이 아니다. 첫 검사는18V를 분리한5V 저항 시험으로 한다. 18V 검사 전에는5V 부하 연결을 제거한다. [핀표·배선·구매 링크·측정 순서](HEAD_TEST_v1_2026-10-11.md)를 따르며, 퓨즈는 노즐 펄스 보호기가 아니라 전원선 단락 보호용이다.

TS3643는 필수 브랜드가 아니다. 16핀1mm 소켓 납땜 완료·독립2.54mm 인출형 범용 보드도 가능하지만 접점 면·리본 두께·전기 정격을 대조한다. 제시된 DeviceMart1330609는0.5mm 연장용이라 제외하고 AliExpress33026153891은 상세 확인 실패로 보류한다. [헤드 접점표](HEAD_CONTACT_v1_2026-10-12.md)의 RC01~16은 원작 그림의 위치 라벨이며 실제 보드 핀 번호가 아니다. 공통 전원2개·노즐 반환12개·미사용2개의 실제 대응은 수령 후 무전원 검사한다.

추가[사용자 상품 화면](reference/ffc_candidate_2026-10-12.png)에서는1.0mm/16P와bent pin/1pcs 옵션을 확인했다. 실제 선택 보드의 사진·소켓 면/두께·정격·상품URL은 미확인으로 남긴다. 배송 일정은 사용자 수용 조건이며 이 화면만으로 헤드 통전을 승인하지 않는다. straight/bent 선택이 가능해straight를권장한다. 고객당1개 제한에 맞춰A3는필수1개만준비하고 예비는 제외한다. 홀더의16핀 리본1개를이 보드1개에서12개 출력과공통 전원으로 나눠 두 MCD 모듈에 연결한다. 분사 모듈2개라고FFC 보드도2개 필요한 것은 아니다. A3의15,000원 가배정은결제액 확인 전 유지한다.

G마켓의16핀/1mm 소켓 장착 범용 보드 후보도 확보했지만 해외직구이고 소켓 정격·홀더 호환·한국 납기는 미확정이다. 국내 잉크젯용297mm/45m/80g 롤지는1롤 판매 링크를 확보했다. 2인치 지관 표시를 P5의 실물 끼움 검사에 사용하며, 롤 외경이나 배송을 확정했다는 뜻은 아니다. 정확한 옵션·현재 가격·국내 발송 여부는 [주문표](ORDER_v1_2026-10-12.md)에 기록한다.

## 5. 원작에서 재사용할 것

원본 ZIP에서 급지 지지물·기어·프레임 연결부 STL과 OpenSCAD를 [참조 폴더](reference/README.md)에 내용 변경 없이 보관했다. 헤드 회로 그림은 별도 헤드 설명 페이지 참조본이다. 15mm 각파이프, 6200ZZ 계열 베어링 지지와 NEMA17 장착부를 바탕으로 재사용한다. 출력 공차에 맞춘 작은 시험 조각을 먼저 출력한다. [원본 파일](https://homofaciens.de/download/WorldPrinter.zip)

새 도면이 필요한 것은 다음 세 부분이다.

1. **P1:** Q2299A를 새 캐리지에 연결하고 노즐 높이를 조절하는 어댑터.
2. **P8:** X축을 내부 프레임에 고정하는 연결부. 하중은 금속과 볼트로 받는다.
3. **P9:** 15mm 내부 파이프와 외부 2020 받침을 연결하는 고정부.

기성 X축을 구해도 이 세 도면이 자동으로 완성되는 것은 아니다. 기존 캐리지·베어링 부품을 새 X축용으로 중복 구매하지 않는다.

3D 출력비150,000원은 재료·시험 출력 포함 가배정이다. 별도 필라멘트 비용을 더하지 않고 출력 업체를 찾지 않는다. 사용자가 제작 방식을 맡는 것과 P1/P8/P9 치수·하중 경로·끼움 확정은 별개이므로 해당 설계 조건은 유지한다.

[기계부 문서](MECHANICAL_v1_2026-10-12.md)에 외부600×440·내부440×400 배치와 원자재/절단 가안을 추가했다. 새 제작 도면으로 검증된 값이 아니므로 D1~D5/E1 등의 주문·절단 승인은 보류한다. P1/P8/P9에 필요한 홀 좌표·높이·금속 적층을 명시했다.

원본 소프트웨어에는 노즐 번호와 실제 핀 번호 처리, 배열 범위, 통신 버전의 불일치가 있다. 그대로 업로드하지 않는다. 지금은 문제 위치만 기록했고, 펌웨어를 새로 작성하거나 수정하지 않았다.

납기가 긴 X축을 먼저 구매하는 것은 가능하지만, 분사 시험 전에는 프로젝트 실패 시 재사용 가능한 기계부를 선구매하는 결정이다. 전체 작동이 보장된 구매로 해석하지 않는다.

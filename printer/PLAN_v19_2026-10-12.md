# WorldPrinter 기반 글리프 롤 프린터 계획 v19

2026-10-12. [재료표 v19](BOM_v19_2026-10-12.md), [선정 근거](SELECTION_v19_2026-10-12.md). [이전 계획 v18](PLAN_v18_2026-10-12.md)은 보존한다.

## 이번 결정

A5를 MCD2803A-02 두 장에서 **MIKROE-233 두 장**으로 교체한다. 국내 판매라는 장점보다 외부18V 사용 경로가 공개된 기판을 우선한다. 기존 모듈의 정격 미확인 콘덴서를 교체하는 작업은 하지 않는다. A7의 개조용220µF/35V 두 개도 구매에서 제외한다. 모듈 자체의220µF를 사용한다.

이는 분사 드라이버의 구매 설계 선정이지 카트리지 분사나 전체 프린터 구동 보증이 아니다. FFC 무전원 확인용1개·예비비, 기계부 미완, 전체 예산 초과는 그대로 남는다. 최종 품목표·부위별 조립 설명서는 남은 설계가 정리된 뒤 발행한다.

## 유지하는 범위

- 종이297mm /인쇄 목표270mm /흑백 /한 행씩 출력·대기·재개 /커터 없음.
- 프린터 전용 신규 Pi4 Model B4GB + 공식27W 한국형 전원 + High Endurance32GB. 기존 Pi와 부속은 디스플레이 전용.
- Pi는 저장·대기열·모션, USB로 연결한 Uno R3는 분사 펄스 담당. USB 시간 간격 자체로 분사 펄스를 만들지 않는다.
- C6602A2개·Q2299A1개·A3 Straight-16P-1PCS1개. FFC 정격·핀 대응은 통전 전에 대조하며 불일치 시 사용하지 않는다.
- Bulk-Man VS17B500mm/Silver, 급지 N17SM-48-5 두 개, DM332T 총3개. X축 별도 모터를 중복 구매하지 않는다.
- I4 ACT244+AHCT14 기판, 모터24V와 헤드18V 외장 밀폐형 어댑터, 각각 퓨즈와 수동 스위치 유지.
- 15mm 내부 파이프·2020 받침과 기성 금속 지지 구조 검토. 받침600×440mm는 전체 완성 외형이 아니다.
- 3D 출력 제작비150,000원. 사용자가 출력/제작 의뢰하며 필라멘트·업체 조사 제외.
- 노출220V 배선·용접·PCB 의뢰·InkShield·400mm 확대는 제외. 저전압 기판 납땜·볼트 조립·드릴은 남는다.

## 분사 연결 변경

```text
Pi USB -> Uno R3 + DFR0224 -> 10k 풀다운 -> MIKROE-233 x2
                                                |
                                        CN1~CN8 DRIVE 출력
                                                |
                                    FFC1개 -> Q2299A -> C6602A

헤드18V 어댑터 -> 2A 퓨즈 -> S1A -> 두 보드 CN10 VCC-EXT
J1: VCC-EXT / CN9 VCC: 미연결 / Uno GND와 보드 GND 공통
```

[갱신한 헤드 연결표](HEAD_TEST_v1_2026-10-11.md)의 **단자 이름**을 사용한다. 이전 MCD의 JP 번호나 출력단 좌우를 새 모듈에 적용하지 않는다. MIKROE 사진에는 암소켓 CN9가 있어 기존 A6 수 핀헤더를 사용한다. 새 보드 두 장에는 각각8채널·4채널을 배정하고 남는 입력4개는GND로 고정한다.

[제조사](https://www.mikroe.com/mikrodrive-board)의 외부 DC9~32V 표기와 [매뉴얼2쪽](https://download.mikroe.com/documents/add-on-boards/other/power-supply/mikrodrive/mikrodrive-manual-v100.pdf)의 CN10/J1 회로는18V 경로 선정의 근거다. 같은 자료의95V 설명, 그림의ULN2804 표기 및 AC 표기는 일관되지 않아 설계값으로 사용하지 않는다. 수령 보드가 ULN2803 계열·회로·25V 이상 콘덴서와 다르면 통전하지 않는다.

첫 전기 시험은18V와 헤드를 분리한5V 저항 시험이다. 이후5V 부하 공급선을 제거하고18V 저항 파형, 고정 헤드 점, 작은 글리프, 한 행 순서로 진행한다. 약3µs/18V는 원작 실험 출발값이며 HP 보증값이 아니다. 실제 파형 확인에는 오실로스코프가 필요하다. 퓨즈나 수동 스위치가 긴 분사 펄스 사고를 자동으로 막지는 않는다.

## 배송·예산

10월 내 도착 우선, 늦어도11월 첫째 주를 목표로 국내 재고·빠른 해외 재고품을 고른다. AliExpress 기존 일정 수용은 유지하지만 새 후보에 도착 표시가 있으면 함께 대조한다. 배송일 재질문을 반복하지 않는다.

DigiKey에서MIKROE-233 재고4개·31,002원/개를 확인했다. 필요2개62,004원이며 VAT10%만 가정한 금액은68,205원 올림이다. A5 배정70,400원을 유지한다. 일반 한국 배송3~4일 안내는 개별 보증이 아니며, 재고 소진 후 제조사4주 리드타임으로 바뀌면 이번 일정의 대체품을 다시 찾는다.

전체 부품·제작 가배정1,528,186원 + 예비비650,000원 = **2,178,186원**. 현재178,186원 초과다. 이번 교체로 가격 절감이 확정되었다고 계산하지 않는다. 최종 합배송·세금·기계부·측정기 비용을 합친200만원 이내 주문표는 아직 미완이다.

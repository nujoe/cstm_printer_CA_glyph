## 조립 중심 간소화 점검

### 핵심 부품 사급 후 완성 전기부 수령

최신 의뢰 범위는 **케이블 양끝 결선·나사단자 체결·전기검사까지 업체가 완료하고 분리 구간은 번호별 플러그로 받는 것**이다. [통합 문의서](ELECTRICAL_REQUEST_v1_2026-10-13.docx)에 장치 예상 배치도와 공손한 발송 문안을 반영했다. 시험 신호·코드 준비·실행·계측·전기적 진단·보완 후 재검사를 업체 범위로 요청한다. 모터·스위치는 벤치 전기 시험이며 실제 이동·급지·출력은 기계 조립 후 별도다. 프레임 전체 조립을 업체 검사 조건으로 삼지 않는다. 아래 사용자 단자 체결 수령안은 이전 기준이다. 부품 모델·수량·회로 기능은 변경하지 않는다.

2026-10-13 최신 결정: **사용자가 핵심 모듈을 구매해 업체에 전달하고, 업체가 회로·배선·검사를 완료한 뒤 사용자는 기계 조립을 진행한다.** 용접은 사용자 작업과 업체 의뢰 모두에서 제외한다. 전기부 납땜은 업체가 맡고, 프레임은 볼트·너트·브래킷으로 체결한다. [업체 연락처·바로 보낼 문의문·구매 담당표](SUPPLIER_INQUIRIES_2026-10-13.md)를 현재 진행 기준으로 삼는다.

- 사급 대상: 기존 선정 모델의 신규 프린터용 Pi/Uno, DFR0224, MIKROE-233 2개, DM332T 3개, 외장 어댑터/완성 코드, 접점 확인용 Q2299A/FFC. 디스플레이용 Pi를 가져오지 않는다. 구매 완료를 의미하지 않으며 전달 전 사급 수락과 초기불량 처리 조건을 맞춘다.
- 업체 조달·작업: I4/A7 소부품, 내부 분배·배선·퓨즈·차단 연결, 센서/모터/헤드 하네스, 제어함 가공·고정·지정 검사. 작은 부품을 사용자에게 개별 주문시키는 경로를 기본으로 하지 않는다. 모터 동봉선은 활용한다.
- 납땜 완료품 유지: A5 MIKROE-233, A8 DFR0224와 A3의 납땜형 옵션. 이번에 추가 호환 기성 보드를 선정한 것은 아니다. I4/A7는 **기존 기능을 조립품으로 받도록 문의**하며 아직 실물·공급 견적은 없다.
- 받을 상태: 결선된 제어부1식, 헤드 연결부1식, 번호가 맞는 완성 케이블. 접점 검사 전 헤드 하네스 생산이나 저항 파형 검사 전 카트리지 통전은 승인하지 않는다.
- 기계부: D1/E5는 가공품, E1은 절단품으로 받고 프로파일·X축 키트·3D 부품을 조립한다. E4 급지롤러 피복은 별도 제작 작업으로 남는다. 모든 부분이 이미 조립식으로 바뀌었다고 표시하지 않는다.

이번은 작업 분담과 문의 범위의 확정으로 부품 모델·수량·회로·기계 치수는 유지한다. 새 공급 견적 없이 완성 조립품의 가격을 만들거나 v26을 발행하지 않는다. 전자부 후보 엠피게이트, 하네스 혁신전자, 금속 메이크잇, 기판 비교 도일랩스의 공개 연락처를 확인했으며 수주·가격·일정은 회신 전이다. 핵심 모듈의 공장 조립과 프린터 연결 후 기능검사는 별개다.

2026-10-13 후속 [기성 모듈과 완성 배선 공급 조사](HEAD_RESEARCH_2026-10-11.md#2026-10-13-완성품-중심-재검토): 기존 모듈은 유지하고 국내 하네스/기판 실장 후보를 구분했다. 이번 조사는 대체 회로·제작 의뢰·주문 확정이 아니며 아래 수령 조건과 구매 보류는 유지한다.

### 완성 배선 수령 기준

2026-10-13 후속 요청으로 **사용자는 볼트 고정과 번호가 맞는 케이블 연결을 맡는다.** 전선 절단·피복 벗기기·압착·납땜·핀 재배열·전기용 수축튜브 가열은 사용자 조립 단계에서 제외한다. 나사 단자가 필요한 곳도 해당 단자에 적합하게 끝처리된 선을 받아 표시된 위치에 조이는 수준으로 제한한다. 이를 만족하는 제품을 아직 모두 선정한 것은 아니다.

전기부는 조립 완료 모듈을 우선하고, 필요한 맞춤 연결부는 **조립 및 지정 기능검사까지 완료해 받는 조건**으로 선정한다. 기성 모듈이 없으면 조립 제작이 필요할 수 있으며, 도면만으로 실제 배선이나 검사를 대신할 수는 없다. 제어함 내부 분배·보드 간 연결도 미리 결선하는 것이 목표다. 현재 부품을 각각 사서 사용자에게 다시 회로를 만들게 하는 방식은 이 기준을 만족하지 않는다.

**완성 배선**은 맞는 플러그가 달려 있다는 뜻만이 아니다. 양끝 단자/핀 번호, 극성·도통·단락 검사, 전압/전류 정격, 길이와 가동 여유, 양끝 동일 케이블 번호가 함께 정해져야 한다. 기존 20cm/30cm/1m 등의 길이는 배치 참고값이며 아직 제작 발주용 재단 길이가 아니다. 헤드 전류 경로에 일반 점퍼선을 쓰거나 색상만으로 핀 대응을 결정하지 않는다.

**검사 구분:** 납땜 외관 검사와 이 프린터 회로의 기능검사는 다르다. 예를 들어 [JLCPCB 기능검사 서비스](https://jlcpcb.com/help/article/functional-test-service)는 고객이 제공한 시험 절차에 따라 특정 기능을 검사하며 Standard PCBA 옵션과 별도 검토가 필요하다. 이 서비스가 본 프린터의 분사·정지 시험을 수락했다는 뜻은 아니다. MIKROE 같은 조립 보드도 C6602A와의 분사 검사를 마친 완성 컨트롤러로 부르지 않는다. 검사할 전원 조건·기본OFF·분사 펄스·정지 기능과 합격 기준을 제작 자료에 넣고 결과를 받아야 `조립검사 완료`라고 기록한다.

구매 단계에서는 **A6, C3/C4, G2-01~05, G4의 원부품을 사용자 직접 배선용으로 일괄 주문하지 않는다.** 제작자가 조달할 부품과 사용자가 받을 완성 묶음을 분리하며 아래 기존 수량/가격은 비교 근거로 남긴다. A7의 시험 저항은 없애지 않고 조립된 시험 부하에 포함한다. G2-04/05 전기용 절연 작업도 제작 단계에 포함하고, E4 롤러 피복은 별도 기계 작업으로 유지한다. 완성 묶음과 그 내부 부품을 중복 구매하지 않는다.

최종 조립도는 `부품 고정 → 케이블 번호 A를 같은 번호 단자에 연결 → 전원 OFF 상태 점검 → 단계별 시험` 순서로 작성한다. 실제 커넥터 사진·삽입 방향·양끝 대응과 실패 시 중단 조건을 포함한다. **수령 후 종이 이송·헤드 높이·인쇄 정렬·발열/연속 운전 시험은 남지만, 사용자가 회로 설계나 배선 제작을 떠맡는 전제는 쓰지 않는다.** 전문 측정이 필요한 헤드 파형 검사는 조립/검사 담당자의 범위로 분리한다.

이번 변경은 수령 조건의 확정이다. 부품 대체·완성 하네스 제작·PCB 설계·검사·공급처 연락을 완료한 것이 아니며, 해당 비용과 납기는 미확정이다. 기존 1,699,143원을 이 조건의 완성 키트 견적으로 사용하지 않는다. 최종 커넥터와 제작 가능 경로를 정한 뒤 해당 묶음만 다음 PLAN/BOM에서 교체한다.

사용자가 금속 가공을 하기 어렵고 제어부는 커넥터 연결·단자 배선 정도를 원한다고 명확히 했다. **현재 설계 전체가 꽂고 조이는 키트는 아니다.** E1 구매처 변경 외에 아래 대체품을 선정했다고 표시하지 않는다. 가공품과 완성 회로의 새 비용·납기는 아직 합계에 포함되지 않았다.

| E4 급지롤러 표면 | 전산봉에 튜브를 씌우고 가열, 원형과 마찰 보정 | 현재는 시험용 제작 방식. 기성 피복/완성 롤러가 치수와 마찰을 만족하면 교체 후보지만 선정 전이다 |
| I4 신호변환부·A7 풀다운부 | 소켓·IC·저항·단자를 만능기판에 납땜 | 제어부의 주요 제작 부담. **직접 납땜용 소부품 일괄 주문을 보류**하고 납땜 완료 회로 또는 기능이 맞는 기성 모듈을 우선한다. 대체 보드와 제작 의뢰는 아직 확정/실행하지 않았다 |
| C4 스위치·G2 헤드선 | 스위치 납땜 러그, 헤드 가동선 양끝 접속·절연 | 연결 완료 케이블/단자형 스위치로 줄일 수 있는지 검토. DC 정격·극성·핀 대응을 확인하지 않은 제품으로 교체하지 않는다 |

D1을20mm 프로파일로 바로 바꾸면 P2/P3/P6/P9/P12/P14의15mm 장착부와 축 높이가 달라진다. 원작 부품을 그대로 끼울 수 있는 교체가 아니므로 이번에 프레임 전체를 바꾸지 않는다. 가공을 외부에서 완료해 받는 경로도 아직 선정되지 않았으며 별도 견적·납기 검토가 필요하다. 치수에 맞는 부품을 조달하지 못하면 해당 부분의 국소 재설계를 검토한다.

## 수축튜브는 두 용도다

| 구매 ID | 어디에 쓰는가 | 판단 |
| --- | --- | --- |
| G2-04 3mm | 헤드 가동선 등 납땜으로 연결한 개별 전선의 노출 금속부 | 전선 절연용. 정상적으로 체결된 USB·WAGO·절연 단자 몸체를 다시 감싸는 용도가 아니다 |
| G2-05 접착식6mm | 고정 전원선 접속부·C4 스위치 납땜 러그 | 전선 절연용. 단자/케이블을 완제품으로 바꾸면 해당 접속부 작업이 줄어든다 |
| E4 12mm | 종이가 닿는 하부 급지 전산봉2개의 약320mm 구간 | 전기용이 아니라 시험용 롤러 피복. 제거하면 나사산 표면이 종이에 직접 닿으므로 전선용 튜브와 묶어 삭제하지 않는다 |

수축튜브는 열을 주면 오므라드는 덮개다. 전기용은 납땜 접속부가 서로 닿는 것을 막는 용도이며 [Adafruit 설명](https://learn.adafruit.com/lets-put-leds-in-things/soldering?embeds=allow)과 구분해 E4의 급지 성능은 별도 시험한다. 케이블 외피 전체나 퓨즈·USB·레버 단자 위에 무조건 씌우지 않는다. 실제 접속부 크기와 수축 후 내경이 맞아야 한다. 롤러 피복에는 전선용 작은 튜브를 이어 붙이지 않는다.

3mm/6mm를 구매 화면에서 `배선 절연 소모품`으로 묶되 서로 다른 용도·규격은 보존한다. 기존3m/1m는 작업 여유 포함 구매량이지 모두 사용해야 하는 길이가 아니다. 규격이 검증되지 않은 혼합 튜브세트로 자동 교체하거나 절연을 생략하지 않는다.

## 제어부에서 유지할 것과 줄일 것

**최신 사용자 명확화:** 볼트·너트의 조달은 괜찮다. 줄여야 하는 것은 미세 전자부품을 하나씩 골라 연결하는 작업이다. 체결재 수량 최적화/재선정은 진행하지 않는다.

- **유지:** Pi↔Uno USB, A8 납땜 완료 단자 실드, DM332T3개와 동봉 모터선, WAGO 분배, 외장24V/18V 어댑터. A8은 [DFRobot DFR0224 스프링 단자 실드](https://www.dfrobot.com/product-846.html)이며 추가 만능기판이 아니다.
- **남은 제작:** I4는 Pi의3.3V 신호를 모터용5V 신호로 바꾸고 부팅 중 출력을 막는 회로다. 완성품이 아니다. A7의 입력을 기본OFF로 잡는 저항과 헤드선 접속도 남는다. MIKROE-233 두 장을 샀다고 이 모든 배선이 완성되는 것은 아니다.
- **추천:** 이미 고른 모터·어댑터·헤드는 유지하고 I4/풀다운부와 헤드선의 조립 작업을 집중적으로 줄인다. 완성 회로로 받거나 검증 가능한 모듈로 대체하기 전까지 `납땜 없이 연결 가능`이라고 표시하지 않는다. 범용 양방향 레벨변환 보드를 핀 수만 보고 대체하지 않는다.
- **삭제하지 않음:** 퓨즈, 전원 차단, 기본OFF 회로, 원점/끝단 입력, 접속부 절연, 실물 보정. 시험용150Ω 저항4개도 상시 설치물이 아니지만 최초 분사 전 검사에 필요하므로 `시험 꾸러미`로 분리하고 누락하지 않는다.

## 구매 목록을 읽는 방법

사용자가 처음 보는 목록은 [주문표의6묶음](ORDER_v2_2026-10-12.md#먼저-볼-구매-묶음)으로 정리한다. 기존39개 ID와 세부 수량은 아래쪽에 남겨 중복 구매를 막는다. 묶음은 안내 분류이지 판매처에서 완성 키트로 배송한다는 뜻이 아니다. 모터선은 동봉분, USB는1개, 점퍼선은A6/I4 합3묶음이라는 기존 합산을 유지한다. 회로 조립 방식을 바꿀 때는 그 묶음의 소부품과 예산을 동시에 대체한다.

다음 선정 작업은 **I4/풀다운부의 조립 완료 조달 → D1/E5의 가공 완료 조달 → G5의 무가공 고정/배선 경로** 순서로 좁힌다. 이 검토만으로 새 부품 주문이나 외주 제작에 동의했다고 해석하지 않는다. 급지·헤드·보호 시험은 그대로 남긴다.

제어부의 추천 검토안은 **기존 I4의 논리 변환/기본OFF와 A7 풀다운 기능을 납땜 완료 인터페이스 보드로 받는 것**이다. Pi·Uno·DM332T·MIKROE는 유지하여 모터와 헤드를 처음부터 다시 고르지 않는다. 이는 현재 구입 가능한 특정 완제품을 발견했다는 뜻이 아니다. 기능이 맞는 기성품이 없으면 PCB 조립 제작의 비용/납기를 대조한 뒤 선택하고, 승인 없이 의뢰하지 않는다. 커넥터만 꽂는 수령 상태를 목표로 하되 헤드 가동선의 접속·절연은 별도로 완성해야 한다. 부품만 실장된 보드가 곧 파형/고장 시험을 마친 보드인 것도 아니다.

### 작은 부품 수가 많은 이유와 실제 절감 대상

- **전자부품:** I4 한 장 안에 IC2종·소켓·저항3종·콘덴서·단자·기판이 따로 나뉘어 있다. 이들을 조립 완료 보드로 받으면 회로 내부의 부품은 그대로 있어도 사용자의 구매·납땜 대상이 줄어든다. 아직 구할 수 있는 완성 보드를 확정한 것은 아니다. 기존25,000원은 소부품값이지 완성 보드 가격이 아니다.
- **볼트·너트:** 현재 M3세트는 이미1세트만 선정했고 추가25/30/40mm 볼트와 와셔는 그 세트에 없는 규격이다. 단순 중복으로 삭제할 수 없다. 100개 포장은 당시 총액이 더 낮아 선택한 구매량이며 전부 장착하지 않는다. 나사 지름만 맞는 혼합 세트로 대체하면 길이·와셔 두께·머리 모양이 달라질 수 있다.
- **파이프 속받침:** D5의 작은 금속 칼라38개는 얇은 파이프가 조임으로 찌그러지는 것을 줄인다. 남은2개는 헤드 고정용 나사 스페이서로 다른 부품이다. 현재 관통볼트 구조에서 칼라만 빼지 않는다. 부품 수를 실제로 줄이려면 해당 고정부의 구조 변경과 명목 치수/하중 검토가 필요하다.
- **구매 화면:** 설치 부품과 시험 부품, 구매 포장 수량과 실제 사용량을 구분한다. 저항·점퍼 등 같은 상품은 합산 주문하되 두 회로에서 같은 한 개를 공유한다고 계산하지 않는다. 새로운 볼트/전선/수축튜브 세트를 추가로 권하지 않는다.

수정 STL·완성 조립설명서·펌웨어·실물 통전 검증은 이번 문서 수정으로 완료되지 않는다. 실제 구매와 공급처 연락은 하지 않았다.

# WorldPrinter 기반 DIY 글리프 롤 프린터 계획 v8

작성일: 2026-10-11 / 변경 기준: v7 및 헤드 연결부 조사 / 상태: 모듈 후보 확인, 구매 조건 정리 중.

재료와 구매 후보는 [재료표 v8](BOM_v8_2026-10-11.md), 조사 근거는 [헤드 조사](HEAD_RESEARCH_2026-10-11.md), 이전 결정은 [변경 기록](CHANGELOG.md)을 따른다. 이 문서는 제작 계획이며 작동 보증이나 전체 주문 승인서가 아니다.

## 1. 만들려는 장치

TouchDesigner에서 생성한 흑백 글리프를 일반 롤지에 한 행씩 출력한다. 다음 행이 준비되지 않으면 기다리고, 준비되면 그 아래에 이어 찍는다. 커팅 없이 종이가 아래로 이어져 전시 중 생성된 데이터가 물리적인 기록으로 쌓인다.

그래픽의 크기·간격·행당 개수는 PC/Pi에서 이미지를 만들 때 정한다. 초안은 36×36 글리프 10개를 한 행에 배치하지만, 종이 폭과 출력 품질 시험 후 바꿀 수 있다. 프린터에 10열을 고정하는 별도 회로는 필요하지 않다.

조립은 기성 축·보드·어댑터, 볼트, 3D 출력 고정부 중심으로 한다. 헤드 구동부에는 소량 납땜이 남을 수 있다. 용접은 계획에 없다. 금속 부재의 절단·드릴은 최종 치수에 따라 필요하며, 재료 표준 길이를 그대로 사용할 수 있는 곳은 가공을 줄인다.

## 2. 유지할 결정과 설계 가정

| 구분 | 내용 |
| --- | --- |
| 유지 | 흑백 잉크젯, C6602A, Q2299A, Pi + Uno, 롤지 연속 출력, 커터 제외 |
| 유지 | 앞뒤 급지 롤러 2조, 수동 공급 롤, 내부 15mm 각파이프, 외부 프로파일 고정 |
| 유지 | 보유 Pi 4 4GB 활용, 납땜 완료 제품 우선, 노출 AC 단자 배선 제외 |
| 보류 | InkShield 구매, PCB/PCBA 업체 제작 |
| 제외 | Mega/MKS 통합안, 두 번째 모션용 Uno, 산업용 폐쇄 루프 축을 기본으로 넣는 안 |
| 설계 가정 | 종이 폭 297mm, 인쇄 폭 약 270mm, X축 유효 이동 약 350mm |
| 설계 가정 | 글리프 10열. 인쇄 가능한 폭·실제 점 간격에 맞춰 변경 |
| 미확정 | 벨트 X축 상품, 모터 드라이버, 모터 전원 용량, FFC 옵션, 최종 프레임 치수 |

297mm는 A3의 짧은 변 길이이고, 롤 출력물의 길이가 420mm로 제한되는 것은 아니다. 297mm 롤을 구하지 못하면 210mm 등 확보 가능한 폭으로 조정한다. 420mm로 다시 확대할 때는 축·프레임·용지·예산을 함께 바꾼 새 버전을 만든다.

## 3. 시스템 구성

```text
메인 PC / TouchDesigner
    | 완성된 한 행의 흑백 이미지 + 고유 row_id
    v
보유 Raspberry Pi 4 4GB
    | 이미지 저장, 출력 대기열, 비트맵 처리, 모션 제어
    |                                  |
    | 검토된 신호 인터페이스 I4        | 검토된 신호 인터페이스 I4
    v                                  v
Arduino Uno R3                  모터 드라이버 3채널
    | 분사 펄스                    | X축 / 뒤 급지 / 앞 급지
    v                              v
ULN 헤드 구동부 A5~A7           기성 벨트 X축 + 급지 롤러
    |
FFC 변환기판 A3 -> Q2299A A2 -> C6602A A1
```

이 그림은 역할 구분도이고 실제 단자 배선도는 아니다. Pi의 3.3V GPIO와 Uno의 5V 신호를 그대로 양방향 직결하지 않는다. I4에서 원작의 신호 방향·입력 임계값·반환 신호 유무와 드라이버 입력 회로를 대조한다. I2C용 범용 레벨 변환 보드를 이름만 보고 펄스용으로 채택하지 않는다.

원작은 Pi가 이미지·모터를 맡고 Uno/ATmega 계열이 분사를 맡는 구조다. 이를 따라가되 Pi 4 운영체제·GPIO 라이브러리·선정 드라이버에 맞춘 조정은 필요하다. 원본을 그대로 업로드하면 완성된다는 전제로 구매하지 않는다. [원작 구성](https://homofaciens.de/technics-machines-WorldPrinter_en.htm)

Uno는 ATmega328P 기반 R3를 사용한다. R4 등 다른 MCU 보드는 이번 목록에 섞지 않는다. 초기에는 Uno를 보드 상태로 사용해 USB로 시험·업로드하며, MCU를 떼어내 별도 최소 회로로 만드는 작업은 생략한다. [Uno R3 제조사 자료](https://docs.arduino.cc/hardware/uno-rev3/)

## 4. 헤드 구동부

Q2299A는 카트리지를 고정하고 접점을 연결하는 홀더다. 분사 제어 보드가 포함된 프린터 키트가 아니다. [홀더 판매 사양](https://www.arrayink.com/hp-q2299a-carriage-assembly.html)

원작의 Uno + ULN2803 2개 회로를 기준으로 한다. 이번 조사에서 태진기술 `MCD2803A-02` 나사단자형 모듈 2개를 우선 후보로 잡았다. 제조사 회로도에서 8채널 직접 입력·직접 출력, COM, 외부 부하 전원 선택이 확인된다. 릴레이·통신 칩을 거치지 않으므로 원작의 12개 독립 노즐 신호를 배선하는 후보로 적합하다. 실제 분사 성능을 검증한 것은 아니다.

**18V 연결은 아직 승인하지 않는다.** 모듈 회로의 `220uF C1`이 부하 전원 `VCC_DRIVE`에 연결되지만 콘덴서 정격 전압은 자료에 없다. 수령 후 정격을 확인하고, 18V용으로 최소 25V 이상인 부품과 맞는 극성을 사용한다. 필요하면 이 콘덴서 한 개를 보드마다 교체하는 작업이 남는다. `JP2`는 외부 부하 전원을 선택하도록 설정하고, Uno 5V와 18V가 연결되지 않는지 무전원 연속성 검사를 한다. 커넥터·보드 부품 정격과 기본 OFF·더미 부하 펄스도 확인한 후 헤드를 연결한다. [제조사 모듈 회로도](https://htckorea.co.kr/image/DK/MCD2803A-02_ULN2803A.pdf)

모듈 가격은 국내 판매 표시 기준 35,200원/개(VAT 포함), 2개 70,400원이다. IC 직접 납땜을 줄이기 위한 비용이며, DIP IC 2개·DIP 소켓을 동시에 구매하지 않는다. 모듈의 10핀 입력 헤더에서 Uno 신호를 꺼내는 배선은 남는다. [국내 후보](https://www.devicemart.co.kr/goods/view?no=16030274)

FFC는 원작 설명의 16핀·1.0mm 피치를 기준으로 찾는다. 접점 방향·삽입 두께·핀 1 대응은 Q2299A의 실제 리본과 맞춰야 한다. 기판만 파는 상품과 커넥터까지 납땜된 상품을 구별한다. [원작 헤드 연결·회로](https://homofaciens.de/technics-machines-printhead-hp6602_en.htm)

부팅·리셋·업로드·통신 끊김 때 분사가 OFF가 되도록 한다. 풀다운만으로 부팅 중 적극적으로 출력되는 펄스를 막을 수 있다고 가정하지 않는다. 부팅 동작 핀을 제외하고 전원/허가 방식과 펄스를 함께 검토한다. 실제 헤드는 더미 부하 시험 이후 연결한다.

이전 초기 설계 문서에는 원본 Arduino 소스의 노즐 인덱스와 핀 번호, 배열 접근에 대한 문제 기록이 있다. 이 문서에서는 그 소스를 다시 검사하지 않았으므로, 재사용 전에 원본 파일 버전과 실제 문제가 있는 위치를 확인해야 한다. 전체 펌웨어 개발은 부품 확정 이후 진행한다.

## 5. 기계 구조와 전원

```text
공급 롤 / P5
    v
뒤 급지 롤러 / P2·P3·P7
    v
평탄한 인쇄면 / E5 <- 좌우로 이동하는 헤드 / B1·P1·P8
    v
앞 급지 롤러 / P2·P3·P7
    v
출력물 받침 또는 바닥의 느슨한 수납

내부 프레임: 15mm 각파이프 / D1·P6
외부 받침: 2020 프로파일 / D2·D3·P9
```

X축은 벨트·가이드·캐리지가 조립된 스테이지를 우선 선정한다. 모터 포함이면 X축 모터를 별도로 추가하지 않는다. 유효 이동량과 전체 길이는 구분한다. 캐리지 구멍, 헤드 무게, 종이 평면과의 거리, 양쪽 끝단 공간을 확인한 후 P1/P8/P9를 그린다.

원작의 앞뒤 급지 원리를 유지한다. 롤러 회전량은 실제 지름·기어비로 각각 보정한다. 출력물 무게가 급지부를 잡아당기지 않게 받침을 둔다. 긴 롤에서는 종이 들뜸·미끄러짐·정전기·헤드 건조가 시험 대상이다.

전원은 외장 어댑터를 사용한다. Pi는 공식급 USB-C 전원, Uno는 시험 시 USB 전원, 헤드는 고정 18V 어댑터 후보, 모터는 선정 축/드라이버에 맞는 외장 어댑터를 쓴다. v6의 24V 5A는 후보로만 남긴다. 신호 기준 GND 연결은 최종 회로대로 하고, 서로 다른 전원의 양극은 합치지 않는다. 18V/24V는 Pi나 Uno의 논리 전원 핀에 넣지 않는다.

고정부에서 힘을 받는 부분은 금속·볼트가 지지하도록 한다. P8의 출력물은 위치와 간격을 잡는 용도이며, 출력물만으로 축을 지탱한다고 확정하지 않는다. 파이프 벽 두께와 체결부 눌림도 확인한다.

## 6. 한 행의 출력 동작

1. TD에서 완성된 글리프들을 한 행으로 묶고 변경되지 않는 이미지와 `row_id`를 전달한다.
2. Pi가 원본 행 이미지를 저장하고 출력 대기열에 넣는다. 수신 확인과 실제 인쇄 완료를 따로 기록한다.
3. Pi가 인쇄 폭과 점 간격에 맞춰 비트맵을 처리한다. 글리프 확대는 정수 배율을 우선 사용한다.
4. X축 이동과 노즐 분사를 맞추며 행 내부의 작은 구간들을 인쇄한다. 필요에 따라 미세 급지를 포함한다.
5. 한 행이 완성되면 설정된 행간만큼 급지하고 인쇄 완료를 기록한다.
6. 다음 데이터가 없으면 멈춰 기다린다. 커터와 강제 페이지 배출은 넣지 않는다.

작품에서 말하는 한 행은 여러 글리프의 묶음이다. 프린터의 한 번 분사나 한 번 X축 이동과 같은 단위가 아니다. 전원 중단으로 일부만 찍힌 행은 자동으로 처음부터 다시 찍지 않고 확인 후 처리한다.

한 행의 내부를 모두 검게 채우는 디자인은 점 수와 출력 시간을 늘린다. 속도는 실제 행 출력 시험으로 측정하고 전시 데이터 수집 속도를 맞춘다. 시간 제한 없이 느리게 출력할 수 있다는 조건은 유지한다.

- [x] 현재 미확정 부품·가정·예산을 분리.

### 단계 1. 최소 분사 시험의 구매 목록 확정 - 지금 할 일

- [ ] A3의 접점 방향·두께·핀 1을 맞추고 정확한 납땜 완료 변환보드 상품을 선정한다.
- [x] 원작 회로와 MCD2803A-02 제조사 회로를 비교하고 나사단자형 모듈 후보를 특정한다.
- [ ] A5~A7 모듈의 C1 정격·입력 하네스·기본 OFF 부품을 정리해 시험 구매 목록을 확정한다.
- [ ] Uno 출력 핀·기본 OFF·헤드 전원 차단을 검토한 핀별 배선도와 통전 순서를 작성한다.
- [x] A3/A5 조사 결과와 후보 예산을 BOM v8에 반영한다.
- [ ] 정확한 옵션·결제 총액·한국 도착 예상·동봉품을 기록한다. 표시 가격과 주문 확정을 구분한다.

통과 조건: A1~A7, C2와 해당 전원/배선 부속을 어떤 상품으로 주문할지 특정할 수 있어야 한다. 실물에서만 확인 가능한 연결은 수령 검사 항목으로 표시한다. 이 단계에서 실제 분사 성공까지 증명해야 하는 것은 아니다.

### 단계 2. 최소 분사 부품 구매와 시험

- [ ] 확정된 시험 부품을 주문하고 수령 사진·접점·연속성·극성을 기록한다.
- [ ] 헤드를 빼고 전원·기본 OFF·더미 부하 펄스를 측정한다.
- [ ] 카트리지를 연결해 고정된 위치에서 제어된 점을 출력한다.

통과 조건: 부팅/리셋/정지 시 오분사 없이 짧은 점을 반복 출력한다. 고정 헤드 시험 성공을 글리프 전체 인쇄 성공으로 표시하지 않는다.

### 단계 3. X축·용지·급지 구성 확정과 조립

- [ ] B1의 모터·드라이버·이동량·장착 구멍·중량과 H1의 용지 폭·지관·롤 외경을 확정한다.
- [ ] B3/B4/C1과 I4를 연결 가능한 사양으로 정하고 전체 BOM과 예산을 갱신한다.
- [ ] P1/P8/P9 치수 도면과 STL을 완성한다. 원작 부품은 시험 끼움 후 출력한다.
- [ ] 헤드 OFF 상태로 원점·끝단·X 왕복·앞뒤 급지를 시험한다.

통과 조건: 출력 폭 전역에서 간섭 없이 이동하고, 종이 1m 급지 시 비틀림·미끄러짐을 측정·보정한다. 안전한 고정과 케이블 장력 완화를 확인한다.

### 단계 4. 작은 글리프에서 한 행으로 확대

- [ ] 성긴 시험 패턴, 36×36 글리프 1개, 여러 개의 한 행 순서로 인쇄한다.
- [ ] 점 간격·행간·순차 분사·이동량을 보정한다.
- [ ] 한 행 완료 후 정지, 다음 행 도착 후 이어 출력하는 동작을 확인한다.

통과 조건: 한 행이 누락·중복 없이 출력되고 글리프 형태가 읽히며, 실제 행당 시간을 기록한다.

### 단계 5. TD 연동과 전시 운전

- [ ] 기존 글리프 전송부를 행 이미지/row_id 전송에 연결한다.
- [ ] 대기열 저장, 인쇄 상태, 재시작 시 중복 방지를 확인한다.
- [ ] 목표 전시 운영시간만큼 연속 시험하고 정지·재시작·카트리지 교체를 반복한다.

통과 조건: 출력 속도가 관객 데이터 수집에 대응하거나 대기열이 충분히 저장되고, 종이/잉크 교체와 중단 행의 복구 방법이 문서화된다. Pi 디스플레이는 큐의 같은 행을 보여주되 인쇄 완료와 혼동하지 않게 한다.

## 8. 예산과 납기

총상한은 2,000,000원이다. 현재 배정은 부품 1,239,920원 + 배송·세금·공구·교체 예비비 650,000원 = **1,889,920원**이다. A5를 모듈 2개 70,400원으로 바꾼 후보 예산이며 전체의 실제 견적은 아니다. 보유품과 동봉품을 제외해 줄인다. 단계별로 주문하며 미확정 전원을 축과 별도로 확정 구매하지 않는다.

수령 목표는 2026년 10월 말~11월 첫째 주다. 현재 모든 상품의 배송일이 확정된 것은 아니다. 출고일·해외 입고일·한국 도착일을 구분한다. Q2299A의 FedEx Express 1~3일은 사용자가 확인한 운송 조건으로 보관하며 판매자 처리·통관까지 포함한 도착 보증으로 쓰지 않는다.

지금은 문서·구매 사양을 정리하는 단계다. 이번 작업에는 실제 주문, 공급처 메시지, 펌웨어 제작, 맞춤 STL 제작, 실물 분사와 장시간 운전 시험이 포함되지 않는다.

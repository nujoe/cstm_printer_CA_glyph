# DIY 글리프 롤 프린터

이 폴더는 `cstm_printer_CA_glyph` 저장소의 프린터 자료다. 앞으로 여기에서 갱신하며 [저장소 현황](../CURRENT.md)을 먼저 확인한다. 기존 `td mcp/printer`는 이전 작업 사본으로 보존한다.

최신 문서 버전: **v25 /2026-10-13**. [계획 v25](PLAN_v25_2026-10-13.md)/[BOM v25](BOM_v25_2026-10-13.md)는 E1을 손잡이닷컴의 스텐304 M10×1.5 절단품5개(400mm2/530mm2/520mm1)로 변경한다. 기존1m3본 구매는 제외한다. E1 가격은 아직 미확정으로 이전 배정액을 잠정 유지한다. v22 기계 배치와 [v24 부속](SELECTION_v24_2026-10-12.md)은 유지한다. [시험용 주문 사양표 v2](ORDER_v2_2026-10-12.md)는 첫 조립·감독하 시험용이며 인쇄 성공·통전·무인 전시 보증이 아니다. 3D 출력150,000원은 사용자 진행, 수정 모델은 작업자가 제공한다. 기존 Pi는 디스플레이용, 프린터 Pi는 신규 구매다.

국내 조달: 297mm/45m/80g 롤지의 국내1롤 판매 후보를 확보했다. FFC의16핀/1mm 옵션과 소켓 사진을 확인한 G마켓 후보는 **해외직구**이며 한국 납기·홀더 호환 미확정이다. Pi 전원은국내608643 공식27W 한국형1개를선정해19,000원VAT 포함·구매UI를확인했다. 기존586785는구매 불가 표시라제외한다. Pi 본체·microSD의현재가격/재고와전원 포함세 품목의발송/수령일은미확정이다. Pi4 4GB 본체와별도24V/18V 전원은유지한다.

AliExpress 배송 일정은 사용자 수용 조건이다. 배송 확인 부족만으로 후보를 제외하거나 같은 확인을 반복 요청하지 않는다. Alibaba는 제외하고 부품 규격·호환 확인은 유지한다. 이는 개별 도착일을 직접 검증했다는 뜻은 아니다.

A3는 [AliExpress1005012643948143](https://ko.aliexpress.com/item/1005012643948143.html)의 `Straight-16P-1PCS` 1개를 무전원 확인용으로 선정했다. [실제16P/1mm 사진](reference/ffc_16p_soldered_candidate_2026-10-12.png)이 근거다. 화면7,500원과 기존15,000원 배정을 유지한다. 소켓 정격·실제 끼움과 접점 검사가 남아18V 통전은 승인하지 않는다. 예비 보드는 지금 사지 않으며 재선정15,000원은 기존 수리 예비비 안에 남긴다.

**조립 중심 재점검:** D1/E5 원자재, G5 미가공 케이스, I4/A7 직접 납땜용 소부품은 구매 보류다. 볼트·너트는 유지하고 미세 전자부품을 조립 완료 보드로 받는 경로에 집중한다. 아직 대체품/조립 제작을 확정하지 않았으므로 전체가 주문 준비된 키트는 아니다. [간소화 점검](PLAN_v25_2026-10-13.md#제어부에서-유지할-것과-줄일-것)을 현행 기준으로 읽는다.

## 읽는 순서

**업체 문의부터:** [업체 연락처·메일 초안·구매 담당표](SUPPLIER_INQUIRIES_2026-10-13.md). 핵심 완성 모듈은 구매 후 사급하고, 남은 소회로·전기 배선·제어함 결선은 업체가 완료해 사용자는 고정·연결한다. 엠피게이트/혁신전자/메이크잇과 비교 후보 도일랩스의 공개 문의 경로를 정리했다. 납땜 완료 A5/A8과 A3 옵션은 유지하며 추가 기성 보드 대체는 아직 없다. 업체 수락·견적·완성품 준비와는 구분한다.

**전기부 수령 조건:** [조립·지정 기능검사 완료품과 완성 배선](PLAN_v25_2026-10-13.md#완성-배선-수령-기준)으로 준비한다. 사용자가 전선을 자르거나 납땜하는 안내는 이전 제작안이다. 기존 원부품표는 제작 참고용이며 완성품 조달·검사·납기·추가 가격은 미확정이다.

**최신 우선순위:** 부품 호환·모델·옵션·수량·구매 링크를 마감해 주문할 수 있게 하는 것이 먼저다. 조립설명서와 최종 도식화는 주문 이후 작업이며, 미완성을 이유로 주문 사양 확정을 늦추지 않는다. 장착 치수·전기 정격의 미확인은 별도로 남기며 호환 완료로 표시하지 않는다.

현재 그림은 설계 검토용이며 완성 조립 설명서가 아니다. 부품 확정 후 부위별 조립 순서·볼트 번호·배선 연결을 도식화한다. 사용자가 3D 모델링을 할 필요는 없도록, 원작 재사용 파일과 작업자가 수정한 STL을 수량·출력 방향과 함께 정리한다. [현재 3D 출력 목록](MECHANICAL_v1_2026-10-12.md#3d-파일과-제작-담당)을 참고하되 시험 모델을 전체 수량으로 먼저 출력하지 않는다.

최신 실행 기준은 **배송받은 부품으로 직접 조립과 단계별 시험을 시작할 수 있는 주문표**다. [주문 사양표](ORDER_v2_2026-10-12.md)에 전체 그룹 수량·계획액과 배송/통전 조건을 모았다. 전시용 자동 보호·장시간 운영은 후속 단계이며,18V 정격과 분사 파형 검사는 해당 통전 전에 필요하다. 이번에는297mm 용지/270mm 인쇄 기준을 유지하고400mm 확대안을 제외했다.

1. [시험용 주문 사양표](ORDER_v2_2026-10-12.md): 먼저 보는6묶음,39개 ID의 실제 모델·수량·링크·보류 조건.
2. [재료표 v25](BOM_v25_2026-10-13.md): 전체 선정 옵션, 수량, 잠정 예산과 구매 보류품.
3. [계획서 v25](PLAN_v25_2026-10-13.md): E1 절단품 변경, 수축튜브 용도, 제어부 간소화 우선순위.
4. [헤드 접점표](HEAD_CONTACT_v1_2026-10-12.md): 범용 FFC 조건, 참조 RC 번호와 무전원 검사표.
5. [기계부 조건](MECHANICAL_v1_2026-10-12.md): P1/P3/P9 시험 CAD와P8 선정 배치·부품 수량. [P8 지지 도면](MECHANICAL_v1_2026-10-12.md#10-p8-간소화-비교안-별도-금속-프로파일-지지)의 제조사 견적은 근거이며 전체 조립/강도 승인은 아님.
6. [헤드 시험 패키지](HEAD_TEST_v1_2026-10-11.md): 헤드 시험 수량·직접 링크·회로·측정 순서.

이전 [헤드 조사](HEAD_RESEARCH_2026-10-11.md)와 v7/v8/v9/v10/v11/v12/v13/v14/v15/v16는 이력으로 보존한다. 전기 연결표에 남은 작성 당시 전체 예산은 이력이며, 현재 총액은 최신 재료표를 기준으로 한다.

## 현재 방향

- C6602A 흑백 잉크 카트리지 + Q2299A 홀더.
- 신규 프린터용 Raspberry Pi 4 Model B 4GB + Arduino Uno R3 1대. Pi가 이미지·대기열·모션, Uno가 헤드 분사를 담당한다. 기존 Pi·전원·microSD는 디스플레이용으로 유지한다.
- X축은 Bulk-Man VS17B 500mm 볼트 조립 키트, 급지는 NEMA17, 드라이버는 DM332T 3개를 기준으로 한다. 조립 완료 스테이지가 아니다.
- 앞뒤 급지 롤러를 유지하고, 공급 롤은 수동으로 풀린다. 커터는 없다.
- 15mm 각파이프는 내부 구조에, 프로파일은 받침·고정에 사용한다.
- InkShield는 보류한다. PCB/PCBA는 미세 부품 납땜을 줄일 검토 경로로 다시 비교하되 아직 회로기판·제작처·견적·발주를 확정하지 않았다.
- 용지 폭297mm, 유효 인쇄 폭 약270mm,10열 배치는 설계 목표다. 최종 인쇄 영역은 조립·출력 시험에서 정한다.
- Pi↔Uno는 USB로 연결한다. Pi↔모터 드라이버는 ACT244 + AHCT14의 I4 회로가 현재 설계 기준이다. 별도5V 어댑터는 추가하지 않는다. 남은 기판 납땜·배선 제작·기능검사는 조립 제작 쪽에서 완료해 받는 조건이며 그 경로는 아직 미선정이다.

현재 부품·3D 제작비 가배정은 **1,699,143원**이다. 신규 Pi·전원·microSD250,000원과3D 출력150,000원을 포함한다. 공구·측정/소모품200,000원은 별도이며 합하면1,899,143원이다. 배송·세금/환율·교체 예비금은 최신 사용자 요청에 따라 이번 합계에서 분리했다. 기계 체결재·배선·케이스·청소/보관의 구매 단위는 상세표로 정했다. 일부 기존 가배정과 개별 납기 미확인이 남아 실제 결제 견적은 아니다. 실제 배송·세금이0원인 것은 아니다.

## 문서 버전 관리

- 같은 버전의 `PLAN`과 `BOM`을 한 쌍으로 관리한다.
- 표현·오탈자는 같은 버전에서 고칠 수 있다. 구조·선정 부품·수량·예산이 바뀌면 두 파일을 다음 버전으로 복사하고 변경 기록을 추가한다.
- 이전 버전은 삭제하거나 덮어쓰지 않는다. README의 최신 버전과 링크를 갱신한다.
- 구매 후에는 해당 부품의 실제 모델·옵션·결제 총액·도착일·동봉품을 다음 재료표에 기록한다.
- 2026-10-12 사용자의 이 저장소 업데이트 요청 범위에서 문서를 커밋·푸시한다. 강제 푸시는 하지 않으며 이전 버전과 참조를 보존한다.

Uno↔헤드·Pi↔모터 신호·24V 분배와 기계 배치의 기존 설계는 보존한다. 체결재는 [v23 상세](SELECTION_v23_2026-10-12.md)에 [v24 추가 수량](SELECTION_v24_2026-10-12.md#d4-추가-주문량)을 적용한다. 다음은 작은 전자부품의 조립 완료 조달이며 가공 원자재의 주문 보류도 유지한다. 수령 후 조립설명서·수정 STL·단계별 시험은 별도다. 실제 끼움·분사·급지·발열은 미검증이며 아직 펌웨어나 통전은 진행하지 않는다.
